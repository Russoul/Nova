# Grammar summary

The complete surface grammar in one place, mirroring
`docs/NovaElaboration.txt` — which stays normative.

## Files and items

- `file`, `import`, `item`, `clause`, `pat`, `fixity`.

## Types

- `T{4}` … `T{0}`, with the precedence levels named.

## Elements

- `t{5}` … `t{0}`, including the eliminators, `⋆` forms, and calc
  chains.

## Polynomials

- `F{2}` … `F{0}`.

## `data` signature types

- `Q ::= U | El q | ((x : D))+ → Q | D → Q`.

## Sugar, listed

- `A → B`, `A / R`, `_` binders, numerals, `l ≡ r ∈ T` as a type.
