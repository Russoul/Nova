# Glossary
%stub

Terms this book uses in a specific sense.

- **Artifact** — the certificate-carrying output of elaboration, the
  kernel's input.
- **Blank** — an elided explicit argument, written `_`.
- **Candidate** — a stored equational lemma the discharge engine may
  apply.
- **Code** — an element of `𝕌`; in Nova a code *is* its type.
- **Discharge** — closing an equational goal from the store.
- **Elaboration** — surface syntax to core artifact.
- **Item** — a top-level declaration in a file.
- **Item macro** — `data` and clausal `def`, which expand into items.
- **Obligation** — an equation the engine assumed rather than derived.
- **Reflection** — the rule that turns a proved equation into a
  judgemental one.
- **Squash** — `∥T∥`, a type collapsed into a proposition.
- **Store** — the accumulated lemmas visible to an item.
- **QIIT** — quotient inductive-inductive type.
