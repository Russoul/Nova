# Universes, codes and types
%stub

`𝕌`, `Ω`, and the single most important simplification in Nova: a code
**is** its type.

## `𝕌` — small types

- `𝕌` classifies codes; a code in type position is that type.
- Cumulativity retired the decoding former `El` from the Foundation:
  writing `El a` is only a ToS spelling, kept inside `data` literals.

## `Ω` — propositions

- Propositions are proof-irrelevant, and a proposition **is** its type
  of proofs (`prop-lift`) — it stands where a type goes, with no
  wrapper. Equality lands here ([Equality](#equality)).

## The base types

- `𝟘` (empty, with `𝟘-elim`), `𝟙` (unit, with `()`), `ℕ`.
- Each is both a type and a code, spelled the same way.
