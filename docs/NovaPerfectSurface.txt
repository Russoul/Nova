////////// NovaPerfectSurface.txt — the perfect (elaborator, printer) pairing //////////

////////// Purpose //////////

This file specifies the PERFECT SURFACE programme: a pretty-printer of
elaborated artifacts whose output is readable to a human, elides
everything a specified recovery procedure can reconstruct, and — the
hard constraint — RE-ELABORATES to equivalent foundation terms,
certificates and skeletons, so the kernel re-checks it. The printer
and the elaborator extensions it presupposes are ONE design (the
pairing), built in lock-step; this file is their contract.

Position among the docs: docs/NovaElaboration.txt owns the surface
syntax and the elaborator; docs/NovaPipeline.txt owns the trust story.
Nothing here moves the trust boundary — printer and recovery oracles
are UNTRUSTED, and a defect in either is at worst a file that fails
structurally or re-elaborates to obligations, never a wrong
acceptance (the kernel gate is untouched).

////////// The governing principle //////////

  AN ELISION IS LEGAL IFF THE RECOVERY PROCEDURE, RUN ON THE ELIDED
  FORM, PROVABLY REPRODUCES WHAT WAS ELIDED — AND THE PRINTER CHECKS
  THAT AT PRINT TIME BY RUNNING THE ACTUAL RECOVERY CODE.

The printer and the elaborator therefore share one implementation of
every inference step (the RECOVERY ORACLES): the elaborator runs an
oracle forward at an elided site; the printer runs the same oracle at
print time and elides only what it verifiably recovers. Round-trip
correctness is by construction, per node — never a property of two
implementations kept in sync. The same rule scales to every sugar
tier: from an elided index up to an item macro, A SUGAR IS ADMISSIBLE
IFF ITS EXPANSION REPRODUCES THE ORIGINAL (checked by re-expansion or
re-elaboration, then comparison).

////////// The round-trip contract //////////

For an accepted item (its Σ-prefix, type A, annotated tree τ):

  elaborate(print(τ)) succeeds in the same Σ-prefix, its erasure is
  α-IDENTICAL to erasure(τ), at A, and the kernel accepts the result.

α-identity (core is nameless, so α-identity is structural equality),
not mere convertibility: it is decidable and cheap, it makes printing
idempotent (print ∘ elaborate ∘ print = print), it keeps golden tests
trivial, and it forbids the printer from silently drifting terms
(η-contraction, folding a goal into an abbreviation — the ProvingFeedback
B-18 hazard — or converting between a calc chain and a trans spine —
the B-21b hazard: the two are NOT interchangeable, since chains run
with an empty Σ-scope). Skeletons and certificates may differ freely
across the round trip — they are regenerated each run, and the kernel
verdict is the equalizer.

Whole-file form (what the implementation actually checks): distilling
a module closure and re-elaborating it must (a) re-parse to
structurally identical indexed surface ASTs while the sugar tier is
the identity, and later, when sugar diverges the ASTs, (b) produce a
final Σ whose entries are α-identical to the original run's, with the
run accepted. The elaborator is deterministic, so (a) implies (b) at
the identity tier; the harness keeps both checks so the contract
survives the tier where (a) stops holding.

Two printer MODES over one engine:

  * DISTILL — the contract above holds. For: rewriting files into
    perfect surface, printing generated items, printing obligations as
    prependable lemmas.
  * DISPLAY — readability may win over invertibility (η-contraction,
    lemma-dependent elision, ellipsis, short ambiguous names,
    certificate→calc-chain rendering). For: reports, hovers, docs.
    Never fed back to the elaborator.

////////// The printer's input //////////

Not the erasure. The erasure has strictly less information than the
surface needs (bare core has no motives; ⋆-payloads — squash
witnesses, coind invariants, propext implications — live in the
skeleton; the using clause determines whether discharge re-succeeds).
The DISTILL printer's input is the ANNOTATED TREE — core plus
skeleton — together with the item's discharge-scope data (using
clause, site-local scopes) and display names. Equivalent formulation,
and the implementation's Phase-1 shape: the elaborated (indexed)
surface tree IS an annotation-carrying spelling of the core term —
docs/NovaElaboration.txt: "the distance between surface and core is
annotations, never names" — so retaining it retains the annotated
tree.

////////// Performance constraints (non-negotiable) //////////

Elaboration performance is a design input, not an afterthought. The
strict-conversion architecture's cost model — CONSISTENT AND
PROPORTIONAL TO WHAT IS WRITTEN, every δ named in the source
(docs/PerfNotes.md, "The αβ-conversion survey" onward) — extends to
the pairing:

  1. RECOVERY IS LICENSE-BOUNDED. Every oracle (argument recovery,
     motive check, overload resolution, ∈-recovery) compares under
     α + the computation rules + exactly the enclosing item's cited
     licenses — never the lemma store, never ambient δ. If recovering
     an elided piece would need a lemma or an uncited unfold, it is
     printed explicitly. (Also the determinism guarantee: which term
     a file denotes never depends on anything but the file.)

  2. THE ANTI-HOLE REQUIREMENTS. The removed hole machinery's
     post-mortem (PerfNotes "The cost of a hole"; the four mechanisms)
     is a requirements list on the recovery oracles:
       * no attempt tax — elided arguments are solved SPINE-LOCALLY,
         during the bidirectional walk, before and outside every ↓;
         a metavariable never reaches a conversion site;
       * no cache demolition — solutions live in the spine frame; no
         metacontext survives it; Σ is never mutated;
       * no tier starvation — recovery succeeds at the spine or is an
         immediate structural error ("cannot infer this argument —
         spell it"); no stuck references ever enter terms;
       * no kernel involvement — recovered arguments are ordinary
         core terms; the core stays bare; implicitness is per-def
         metadata (like fixities), invisible to kernel and theory.
     Plus: rigid first-order matching only — no higher-order
     unification, no postponement, no backtracking, one deterministic
     pass.

  3. THE BUDGET GATE. DISTILL refuses an elision whose recovery
     exceeds a fixed budget (a deterministic step count, not wall
     clock). The corpus wall time is a tracked number of the golden
     fixture: a distilled corpus must re-elaborate within a stated
     tolerance of the explicit one. The deblank episode (a ~45×
     invisible cost cliff, found only by measurement) must be
     impossible by construction: elision is granted per-site by
     verified measurement, never by hope.

////////// Citations are semantic //////////

Under strict conversion the using clause is part of an item's meaning,
non-monotonically in both directions (ProvingFeedback B-17: adding a
hinted .eq can UNDO a proof; B-22: license kinds differ — a plain
citation buys whole-equation match and hops, .rw activates rewriting
item-wide). Consequences:

  * the printer reproduces citation sets EXACTLY by default, license
    kinds included;
  * citation MINIMIZATION is a distiller feature, implemented as the
    measured pass ProvingFeedback records (remove one, re-elaborate,
    keep the removal iff the item still closes), one at a time, per
    kind — never a blind sweep;
  * elision recoverability is computed under the item's citation set,
    and the round-trip check runs under the same set.

////////// The sugar tiers (the phased plan) //////////

Each tier lands as a vertical slice — oracle, printer rule, elaborator
rule (grammar + elaboration), round-trip goldens — with the oracle
first, exercised by a printer SURVEY (report-only counts over the
corpus: what would elide, what fails recovery, worst budget) before
any surface form is committed. The strict elaborator's hot path is
touched only in a slice whose survey has made the case.

  Phase 1 (this phase) — IDENTITY TIER + HARNESS. A distill printer
    whose output is today's surface, from the retained indexed surface
    AST; the round-trip harness (print → parse → AST-compare →
    re-elaborate → accept, over the corpus); `nova distill`; goldens.
    No elaborator changes beyond retention plumbing.
  Phase 2 — BIJECTIVE TIER. Numerals, binder-group compaction
    ((x y : A) →), layout. Touches the parser; zero inference risk.
  Phase 3 — IMPLICIT BINDERS + SPINE RECOVERY. {x : A} in def types,
    f {x ≔ t} named overrides, _ for ad-hoc elision of explicit
    binders; implicitness as per-def surface metadata; the spine-local
    rigid first-order oracle under constraints 1–3 above.
  Phase 4 — REMAINING ORACLES, in value order: ∈-elision in equality
    props; motive elision (constant-motive and abstract-the-scrutinee
    checks, checking position only); type-directed operator
    disambiguation (print bare iff resolution in the file's import
    environment uniquely recovers the same Σ name).
  Phase 5 — ITEM LEVEL + DISPLAY DIVIDENDS. Clausal-def/data
    recognition by re-expansion + comparison; citation minimization;
    certificate→chain DISPLAY rendering; reports/LSP onto the shared
    engine.

////////// Phase 1, precisely //////////

Scope: the identity sugar tier. The printer consumes ModUnits — the
loader's parsed modules, whose items are the indexed surface ASTs the
elaborator consumed — and renders today's surface grammar back, with
faithful precedence, fixity-aware infix layout, binder names as
retained, and the file's import/fixity/item interleaving preserved
(fixities interleave with items in corpus files and take effect for
the rest of the file; hoisting one could re-classify an earlier
prefix use of the operator).

The `nova distill <root> <outDir>` command:
  1. loads the root's module closure, elaborates it, requires
     acceptance (a distiller only transforms accepted inputs);
  2. renders every module of the closure into outDir (module paths
     mirrored; the root keeps its basename);
  3. reloads from outDir and verifies, per module: imports, fixity
     declarations, and items re-parse STRUCTURALLY IDENTICAL (the
     range-insensitive Show instances are the comparator);
  4. re-elaborates the distilled closure and requires output
     IDENTICAL to step 1's (determinism makes string equality the
     strongest cheap check);
  5. reports counts; any mismatch names the module and item.

Verification layering, and which check survives which phase: step 3
(AST equality) is the identity-tier contract and will be RELAXED per
sugar tier as printing legitimately diverges from the source spelling
(numerals, grouped binders, elisions); step 4 (accepted, identical
elaboration) is the contract that never relaxes — at later tiers it
tightens into Σ-entry α-comparison against the original run.

Out of scope for Phase 1, deliberately: layout beauty beyond
readable one-item-per-line output (a proper layout engine arrives
with Phase 2, where it matters); printing obligations through the new
engine; any elision.

////////// Status //////////

Phase 1: implemented — Nova.Distill (the renderer and the module
round-trip verifier), the `nova distill` CLI command, ModUnit's
retained interleaved body (Loader/Parser), distill goldens under
tests/nova/distill, and check-distill.sh (the corpus round-trip
gate).

Phase 2: implemented — the bijective tier. NUMERALS: a decimal
literal is surface sugar for a ground S-tower (elements and clause
patterns; the printer emits numerals for values ≥ 2, keeping Z and
S Z structural — the corpus idiom). MULTI-NAME BINDER GROUPS:
(x y : A) → B binds each name past the first at the WRITTEN domain
weakened by its predecessors (Surface.shiftTy/shiftElem — index
arithmetic, no re-parsing; the group's names never scope over each
other's domains), at the type and 𝕌-code levels; the printer
coalesces shift-equal telescope runs back, so hand-split and grouped
spellings print identically. One deliberate grammar shift: an
element-level `(x y : T) → u` previously read as an ascribed
application domain; the binder-group reading now wins (the corpus
and test suite contain no such spelling). LAYOUT: a small
Wadler/Oppen Doc engine (group = try flat, else break; hard breaks
force enclosing groups) at width 100, with the item laid out
seam-first — type, using clause and body each against the width
alone, so a long body never forces breaks inside the type (the
greedy engine's cross-seam pollution), application spines break
one-argument-per-line at uniform indent, telescopes at binder
seams, chains at links, using lists at commas. All Phase-2 sugar is
AST-bijective, so the identity-tier verification (AST equality +
identical elaboration) is unchanged and stays green over the whole
corpus, byte-idempotent on a second pass.

Phase 3a: implemented — the recovery ORACLE (Nova.Recovery) and the
corpus SURVEY over it (`nova survey <file>`), per the oracle-first
sequencing above. The oracle is the simultaneous rigid first-order
matcher: holes solve only at subterm slots (never in an applied-head
position — no higher-order unification), sources are the spine's
expected type (when the bidirectional mode knows it — tracked by a
purely syntactic ⇐/⇒ walk over the erasures) and the types of later
explicit INFERENCE-form arguments; per def, the implicitizable set is
the fixpoint of "recoverable at every site". Measured on the corpus
(94 modules, 2026-08):

  1,901 of 3,577 binder positions implicitizable (53%); 760 of 1,131
  used defs gain at least one; 7,672 of 54,748 argument occurrences
  elidable. Zero positions blocked by partial application. Top
  yields are the ergonomic pain points: equality.sym {A a b} (867
  occurrences), id.eqToId, groupTheory.gop {G} (the group WITNESS
  correctly stays explicit — data, not index), vectByIndAppend
  .vappend {n m a}.

Two-sided caveat, recorded: per-site the numbers are a CEILING
(ground instantiations stand in for the inferred types the real
recoverer will match — a real inferred type can differ up to
computation), while the SITE COUNT is an UNDERCOUNT (spines inside
erased proofs — chain justifications, ⋆-witnesses — do not survive
into Σ, and those are lemma-application-heavy). The verify pass of
Phase 3b (elide-then-check at print time) replaces the ceiling with
a guarantee. VERDICT: the measured case for the surface form is
made; Phase 3b (the {x : A} binder syntax, per-def implicitness
metadata, elaborator-side recovery at application spines, printer
elision under the round-trip contract) proceeds.

Phase 3b: implemented — the surface form and the elaborator-side
recovery. GRAMMAR: {x y : A} binder groups in item types (Π-only;
STyImpPi — elaborates exactly as STyPi, the core stays bare), and
{t} override arguments in application spines (NB `{-` opens a
comment: an override starting with an operator token needs the
space, { -x }). METADATA: implicit positions of the leading
Π-telescope are recorded per Σ-name at item acceptance
(ElabSt.impls) — like fixities, derived from the file, invisible to
kernel and theory. ELABORATION (elabImpSpine): at a spine headed by
an implicit-bearing def, implicit positions up to the last written
argument are inserted and solved by the Phase-3a oracle in ONE
deterministic pass — the expected type first (matched against the
instantiated telescope tail; this is what lets a λ argument's domain
arrive solved), then the inferred types of explicit inference-form
arguments left to right; matching is syntactic, then both sides
under the δ-free computational normalizer, with the mixed-El case
(a bare hole under El binds to code(B) of a decoded rigid type);
solved domains check normally, hole-bearing domains take the
infer-then-convert route whose ↓ emits the ordinary certificate or
obligation. An unsolved position is a structural error naming the
{…} remedy. Trailing implicits are NOT inserted (a bare reference
stays the plain function — v1; the corpus survey measured zero
sites needing more). The anti-hole requirements hold by
construction: spine-local, no Σ mutation, no metavariable ever
reaches ↓, no postponement; an implicit-free run pays one boolean
per application node (corpus wall time unchanged, 6.3s vs the 6.7s
baseline). The distiller round-trips implicit-using files at the
identity tier unchanged (goldens: elab-implicit-accept/-reject,
distill-implicit; nested recovery — sym2 (sym2 h) — included).

Phase 3c: implemented — the IMPLICITIZE distiller mode
(`nova implicitize <file> <out-dir>`, Nova.Implicitize), the first
mode where the AST check legitimately relaxes and the Σ-gate takes
over. Pipeline: survey the accepted Σ for candidates; transform to
the OVERRIDE FORM ({}-binders + every candidate argument wrapped as
a {t} override — semantically identical), whose elaboration runs the
TRIAL hook: at every override, the hypothetical elided recovery
replays with exactly elision's sources and records whether it
reproduces the written value α-EXACTLY (a position past the last
surviving explicit argument records failure — trailing implicits
are not inserted, so the elided site would be a partial
application); fold by INTERSECTION (v1: a position survives iff
every site recovered it — the final corpus carries no overrides);
drop-transform and verify: re-parse identity, elaboration accepted,
kernel Σ entrywise α-identical to the original run's. The Σ-gate is
ITERATED: nested elisions can cascade recovered SPELLINGS in ways
the per-site trial cannot exhibit (a convertible-but-different
inner spelling shifts the outer inferred types), so an α-drift is
attributed by a parallel tree diff to the nearest def-headed spines
whose arguments differ, those defs revert, and the stage re-runs to
the gate's fixpoint.

Two defects the pipeline itself caught and fixed, recorded: the
matcher originally bound holes to ground subterms found UNDER
BINDERS without strengthening — bindings escaped their scope
over-indexed; the matcher now tracks binder depth and STRENGTHENS
every captured binding (failing when it mentions a crossed binder),
which also makes survey, trial, and real recovery scope-agree. And
the trailing-implicit divergence above.

Measured on the corpus (94 modules): 262 defs implicitized, 654
binder positions, 2,163 argument occurrences elided; 1,245 ceiling
positions rejected by the exact trial (the survey ceiling is
generous — real inferred types differ from instantiated domains up
to computation) and one def reverted by the α-gate
(ratBound.bndVia). The implicitized corpus elaborates in ~7.0s
against the explicit corpus's ~6.3s — recovery pays ~0.7s for the
2,163 recovered arguments, proportional, no cliffs.

Phase 3d, first slice: LICENSED-JOIN MATCHING — recovery's third
matching tier (after syntactic and δ-free comp): both sides
normalized by the site's licensed join, comp ∘ unfold[cited]
(engJoin's own vocabulary), captured bindings still α-verified
downstream, so value-spelling drift keeps getting rejected while
definitional SCAFFOLDING the site itself licensed is seen through.
Measured effect: small (+7 positions, +13 occurrences) — and the
verdict census the same slice added explains why. Of 10,206
override verdicts on the corpus:

  5,460 elidable · 4,229 TRAILING · 65 stuck-at-intro
  · 133 unsolved · 319 spelling-drift

Matching failures (unsolved + drift + stuck ≈ 5%) were never the
wall. The dominant blocker (41%) is the TRAILING rule: all-implicit
lemma shapes — qMulComm {a b}, leQZeroBound {n m} — whose every
argument recovers from the expected type, but whose fully-elided
form would be a bare reference, which v1 never inserts. The yield
lever is therefore TRAILING-IMPLICIT INSERTION.

Phase 3d, second slice: TRAILING INSERTION with the NO-INSERT
MARKER (the decided design). In CHECKING position, a reference or
spine of an implicit-binder def INSERTS its trailing implicit run —
written arguments consume positions as before; when they run out,
consecutive implicit positions insert as holes, stopping at the
first explicit position — solved from the expected type like every
hole. Inference positions never insert (a bare reference stays the
plain function). The FUNCTION-PASSING form is the marker `f {}`
(empty braces: zero implicits, give me the function), suppressing
insertion at that reference; the implicitize transformer emits it
automatically at every bare reference of an implicitized def (the
original corpus is fully explicit, so a bare reference always
denotes the function) — 2 markers over the whole corpus. The trial's
trailing verdict relaxes accordingly: a trailing position is
elidable when the site is checked (the consumed positions past the
last explicit are all implicit by construction, so insertion reaches
it).

Measured: verdicts moved to 7,610 elidable / 1,976 trailing / 65
stuck / 166 unsolved / 389 drift, and the corpus yield to 414 defs,
1,003 binder positions, 2,826 argument occurrences elided — all
gates green, implicitized corpus at ~6.7s. The residual trailing
verdicts are INFERENCE-position sites — dominantly CALC-CHAIN LINKS,
whose justifications are deliberately type-undetermined (e-chain:
the link may prove a sub-equation), so insertion is impossible there
by design; commutativity-style lemmas used as links therefore keep
reverting under the intersection policy. Remaining levers: per-site
{…} overrides (though at link sites the override braces would wrap
the very arguments being kept — questionable ink), and the budget
instrumentation of the oracle.

COMMENT PRESERVATION: implemented — the in-place-rewrite blocker
falls. Comments never reach the AST (the lexer strips them), but
their ranges ride in ModUnit.mtokens and the source text is now
retained (ModUnit.msrc), so the distiller re-slices and RE-ATTACHES
them: each comment goes to the first body entry (fixities carry
ranges now too) whose span it precedes or falls inside — an
intra-item comment hoists ABOVE its item, since a rendered item has
no stable interior positions — comments before the first entry form
the file header (printed above the imports; a comment between
import lines floats up there too), and comments after the last
entry the epilogue. Attachment is idempotent by construction:
re-parsing distilled output finds every comment immediately before
its entry. Both `nova distill` and `nova implicitize` output now
carries the full commentary; the corpus round-trips byte-idempotent
with comments in place. (The corpus has only `--` line comments; a
block-comment continuation line would be defensively re-prefixed.)

Phase 4: implemented — ∈-ELISION, MOTIVE ELISION, and OPERATOR
OVERLOADING.

OVERLOADING (a language feature, not just printing): several defs
may share a surface token — each module its own `+` — and opening
more than one makes the name OVERLOADED (ElabSt.dupNames: a name
visible with two or more distinct Σ targets). A reference resolves
TYPE-DIRECTEDLY at the site: every candidate spine is PROBED whole
(probeM — state-discarded, failure-absorbed), and a candidate FITS
iff it elaborates with ZERO NEW OBLIGATIONS — the ↓ judgements
never fail, so plain success cannot discriminate (a wrong candidate
would simply assume absurd equations). Exactly one clean fit
commits and re-elaborates for real; none or several is a structural
error naming the qualification remedy (the mention form (M.op), or
opening only one candidate). Probing runs through elabImpSpine, so
overloads compose with implicit binders and trailing insertion; a
bare overloaded reference resolves in checking position by the
expected type and errors in inference position. Overloaded tokens
must AGREE on fixity (the parse is shared; only elaboration
distinguishes) — a conflict is a load error. Deterministic and
file-determined throughout: candidates come from the file's imports,
the fit criterion from the site's own scoped conversion. A run
without overloads pays one list-membership test per application
node (dupNames is empty). THE CORPUS OPERATORIZATION (2026-08-20): done, via the general
`nova rename <root> <out-dir> old=new …` tool (Nova.Rename): an
AST-level Σ-rename across the closure — definition headers,
references (bare stays bare, qualified stays qualified),
using-citations (renamed citations come out fully qualified),
import opens — verified by acceptance plus kernel-Σ α-comparison
MODULO THE RENAMING (renameSig applies the map to entry names and
every SigVar). Renamed: intAdd/qAdd/realAdd → `+` (infixl 6),
intMul/qMul/realMul → `*` (infixl 7), realSub → `-` (infixl 6),
LeN/LeZ/LeQ/LeR → `≤` (infixl 4), LtQ/LtR → `<` (infixl 4) — one
token per concept across ℕ/ℤ/ℚ/ℝ, resolved per site. The corpus
now reads `(u v : El Q) → u + v ≡ v + u` and
`El (x ≤ y) → El (y ≤ z) → El (x ≤ z)`.

Performance of resolution, measured and fixed to the cost model
(the operatorized corpus elaborates at ~7.8s against the ~7s
un-overloaded baseline; the naive version was 75s):

  * arguments PRE-ELABORATE ONCE per site; candidates are tried on
    types alone and the winner reuses the work (probing whole
    argument subtrees per candidate is exponential in nesting);
  * STAGE-1 QUICK FILTER: argument types match candidate domains
    under α/comp/licensed-join (the matcher — no engine machinery);
    a unique survivor commits directly, and the real run's own
    conversions still verify it. Conversion probes remain as
    STAGE 2 for ties or an empty filter;
  * probes set ElabSt.probing: the assume path skips the
    whole-store hint probe and (on clean runs) the dedup-key
    rewrite normalization — discarded state is pure counting;
  * multi-run drivers clear the global name index between runs
    (clearSigEntryIx): a rename reuses names with changed content,
    and a stale positive entry would leak the old spelling into the
    new run — the one cross-run staleness the caches' "Σ only
    extends" assumption did not cover. GRAMMAR: the ∈-annotation of an equality (type and
Ω-element forms) and the inline motive of ℕ-elim/⊎-elim/quot-elim
are OPTIONAL. ELABORATION: an ∈-less equality infers its LEFT side
for the domain (right as fallback when the left is an intro form —
a deterministic rule, not a search; both intro is a structural
error naming the ∈ remedy); a motive-less eliminator is
checking-only — the motive is recovered by ABSTRACTING the
scrutinee in the expected type (Recovery.absT), so instantiating it
back reproduces the expected type and the switch is α-trivial. Both
recoveries are subject to SKELETON-FREEDOM: a synthesized
annotation ships with an empty skeleton, so it may not contain
stuck eliminators (bare core ℕ-elim/⊎-elim/quot-elim need kernel
payloads an empty skeleton cannot carry) — the verdicts require it
and the elided rules error early on it. EMISSION: the distiller's
acceptance run doubles as the SUGAR TRIAL (per written annotation:
would the elided form recover it α-exactly?), the transform elides
the positive verdicts, and the round trip verifies against the
kernel Σ (α-identical) — the AST check compares against the
TRANSFORMED trees. One cross-sugar interaction, handled: an
∈-elided equality INFERS one side, so that side's ROOT motive stays
written even when its own verdict allows elision. Two parser
consequences: `using` is now a reserved identifier (an ∈-less
equality's right side is an application chain that would otherwise
swallow a following using-clause), and a bare ⋆ right side of an
∈-less equality prints parenthesized (`… ≡ ⋆ using (…)` would
reparse as the ⋆-using proof form).

Measured, and REWRITTEN IN PLACE: 1,783 of 1,937 written
∈-annotations and motives elided across the corpus (92%) — the
equational library now reads `(n : ℕ) → Z + n ≡ n` with induction
proofs `ℕ-elim ⋆ (k ih. ⋆) n` — verified by the Σ-α-gate,
byte-idempotent, canonical form re-established and enforced.

THE BLANK TIER (2026-08-20): a bare `_` at an explicit Π position
of an applied ordinary definition is a per-site elided argument —
in elaboration it IS a hole at its position, entering the same
joint spine solve as the inserted implicits (same placeholder, same
sources, same resolution; unsolved is a structural error). A blank
defers past implicit positions (those are elided by default — {t}
overrides them) and is refused in constructor/eliminator spines,
whose QSort-internal telescopes the matcher cannot see through.
Emission: the sugar pass routes every Σ-headed ordinary spine
through the spine elaborator and runs the BLANK TRIAL per site —
the candidate set grows greedily left to right, each addition
verified as ONE JOINT hypothetical solve that must reproduce every
hole α-exactly (the implicit insertions included, since their
sources may be the ones blanked away), in EVERY MODE the site might
face: with the expected type and without it (an enclosing blank
flips an argument spine from checking to inference at
re-elaboration, and the spine cannot know). Three further gates,
each learned from a corpus counterexample: (i) ELIGIBILITY — a
candidate's committed skeleton must be kernel-rederivable when
dropped to bare (payloads at most trivial switches): a value can be
α-recoverable yet carry a licensed conversion whose certificate
lives in the skeleton (uip's `refl a x` at `Id a x y`, closed only
by hyp.rw) — blanking it would lose the certificate; (ii) SOURCE
ADMISSIBILITY — a checked argument's inferred type feeds the trial
only when inference commits the SAME core as checking did (a probe,
discarded), since a mode flip must not change the argument
(trailing insertion, expectation-solved implicits); (iii) the
FIXPOINT — emission re-verdicts the emitted corpus until a round

PARAMETERIZED MODULES (2026-08-22): a file may open, after its
imports, with a MODULE HEADER —

  module {G : 𝕌} (g : El (IsGroup G))

— a telescope every def in the file abstracts over. The license is
DECLARED, not inferred (bijective-tier in character): each def
elaborates at the parameter context and is Π/λ-CLOSED over it
before it reaches Σ and the kernel, so the entry is byte-identical
to the fully-spelled def's — the groupTheory migration is
Σ-α-identical by construction. Inside the module a sibling
reference auto-applies the parameter prefix (gop x y means gop
{G} g x y): the prefix positions enter the spine solve as
PRE-SEEDED SLOTS — solutions given, not holes — so written
arguments, {t} overrides, and blanks all flow past them unchanged,
and every downstream mechanism (recovery, trials, emission) sees
an ordinary spine. An importer instantiates with

  import (groupTheory g) (gop, ginv, …)

whose arguments elaborate ONCE, at the importer's own parameter
context, THROUGH THE SPINE SOLVE itself (any member def carries
the prefix) — explicit parameters written, implicit ones recovered
from their types — then weaken to each use site. Plain imports are
unchanged: the def's telescope starts with the header params
(header plicity, then the def's own implicit positions shifted),
so existing sites spell exactly what they spelled before. The
header line and instantiated imports print and re-parse through
the same grammar; the round-trip and canonical-form gates extend
unchanged.

POSTFIX OPERATORS AND RENAMING IMPORTS (2026-08-22): a third

any declared operator. The mention form (⁻¹) passes it as a

ARE `·`, `⁻¹`, `e` (user decision: actual names, not aliases):

  module {G : 𝕌} (g : El (IsGroup G))
  infixl 7 ·
  postfix 9 ⁻¹
  def · : El G → El G → El G ≔ g .π₁ .π₁
  def gAssoc : (x y z : El G) → x · y · z ≡ x · (y · z)
  def gInvUniq : {x y : El G} → (x · y ≡ e) → x ⁻¹ ≡ y

THE CONSTANT SOLUTION, TRIED AND WITHDRAWN (2026-08-21, the third
withdrawn design): ?B t̄ = g solved as λ̄_. g when Miller does not
apply (pairextD's {B} occurs only as ?B (x .π₁) — a projection, not
a bound variable, outside the unique-solution fragment). Hardened
twice — constants ran as a strictly-second sweep so a guess could
never preempt a Miller solution, then Huet-style occurs-pruning
refused grounds mentioning an applied argument — and still killed
by a probe: at a genuinely dependent pair in an inference position
the ground mentions v .π₁ while the applied argument is u .π₁,
equal only PROPOSITIONALLY (via the first proof), so the pruning
cannot see the dependency it hides. The falsifier lives in x and
y's TYPES, which the matcher never visits: the wrong guess
surfaces not as an error but as UNPROVABLE OBLIGATIONS with
misleading hints — a trap in the discharge workflow, strictly
worse than "cannot infer". The lesson, recorded for any future
non-unique tier: a GUESSED solution is only admissible with
post-verification against every occurrence of the hole (an
obligation-free probe re-elaboration); syntactic guards asymptote
short of soundness. The non-dependent case needs no tier at all:
pairext's {B} is a bare hole — use pairext at A ⨯ B, pairextD at
(a : A) ⨯ B a, overriding {B} at inference positions.

CAPTURE-TYPING SOURCES (2026-08-21): the principled mechanism the
constant tier approximated. A solved hole's value is a bare,
skeleton-free core, so its type INFERS (kInferBare — kernel
inference, absent for intro forms), and final instantiation will
demand that type convert with the hole's instantiated domain: the
pair (declared domain, inferred type) is a REAL equation of the
site, not a guess. After the pattern pass, each such pair joins the
source list as (Just pos, inferred type) — the pass already knows
how to match a position's instantiated domain — and the pass
re-runs for still-unsolved keys, to a fixpoint bounded by the
unsolved count. The Σ-typed case is the payoff: matching
(a : ?A) ⨯ ?B a against the value's actual Σ-type puts ?B a under
the Σ's own binder, where the Miller tier solves it UNIQUELY —
pairextD's {B} from the pair's type, DEPENDENT OR NOT (the probe
that killed the constant tier now solves B ≔ λm. Id ℕ m n
correctly, and its residual obligation is byte-identical to the
hand-annotated spelling's — inference reproduces exactly what the
user would have written). Strictly additive: round 0 is the prior
engine verbatim; derived rounds only fill holes it left unsolved.
The kernel Σ used for inference may lag obligation-bearing items —
absence just skips the source. ~10.2s plain elaboration, unchanged.
