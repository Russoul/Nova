////////// Preface //////////

This file contains a formalisation of Nova's type theory: Extensional Computational Type Theory.
We present the theory extrinsically: https://ncatlab.org/nlab/show/intrinsic+and+extrinsic+views+of+typing

Semantics to syntactic forms is assigned via evaluation and canonical forms.

NOTE: well-formed terms need not normalize in an inconsistent context.
Equality reflection makes typability hypothesis-sensitive: e.g. under
Γ ∋ h : (A ≡ (A → A) ∈ 𝕌), reflection gives El A ≐ El A → El A, so
self-application types and ω ω is well-formed at El A, where ω ≜ λx. x x
— yet ω ω has no normal form. Normalization is therefore a property of terms
in consistent contexts only; any procedure that beta-normalizes a
well-formed term (as the checker does when storing and comparing facts)
may diverge under inconsistent hypotheses. This is a liveness caveat, not
a soundness one: a non-terminating normalization never certifies a
judgement.

//////////// Type Theory /////////////

We have:
 * Empty type: 𝟘
 * Unit type: 𝟙
 * Natural numbers type: ℕ
 * Dependent product type: (→)
 * Dependent sum type: (⨯)
 * Equality type: (≡) with reflection
 * A universe: 𝕌
 * Quotient type: (/), by an Ω-valued relation
 * A universe of mere propositions: Ω (squash ∥-∥, propositional extensionality)
 * Quotient inductive-inductive types (QIITs): a SCHEME (not a single
   former) — signatures `qiit 𝒮` declaring mutually-defined, possibly
   index-dependent sorts with point AND equation (path) constructors,
   and the dependent eliminator each signature licenses. This subsumes
   ℕ and (/) (each a one-line signature), including indexed inductive
   types and quotient inductive types as special cases; its equation
   constructors are INDUCTIVE (they may relate constructor terms across
   indices and participate in the induction). ℕ and (/) are retained
   for now.

///////////// Syntax ///////////////

x ::= <signature-entry-identifier>

// signature context
Σ ::= ε
    | Σ (Γ ⊦ x ≔ a : A)     // term definition
    | Σ (Γ ⊦ x ≔ T type)    // type definition
    | Σ (Γ ⊦ qiit 𝒮)        // quotient inductive-inductive declaration:
                            //   adds all of 𝒮's sorts and constructors to
                            //   Σ at once (see "Quotient inductive-inductive
                            //   types" below for 𝒮 and the rules it licenses)

// typing context
Γ ::= ε      // empty typing context
    | Γ ᐅ T  // extended typing context

// Γ‖ₙ: the (n+1)-th type in Γ counting from the right (0 = the innermost
// extension), i.e. the type ☐ₙ names before weakening.
(Γ ᐅ A)‖₀     ≜ A[↑]
(Γ ᐅ A)‖ₙ₊₁   ≜ Γ‖ₙ[↑]

// typing context substitution
σ, τ ::=
       ·             // empty substitution
     | σ, t          // extension substitution
     | σ ∘ σ         // composition substitution
     | id            // identity substitution
     | ↑             // weakening substitution

// typing context normal substitution
e˲, t˲, p˲ ::= · | t˲, t

// type
T ::= x [e˲]         // type in the signature context
    | 𝟘
    | 𝟙
    | ℕ
    | 𝕌              // universe type
    | T → T          // dependent product type (Π)
    | T ⨯ T          // dependent sum type (Σ)
    | t ≡ t ∈ T      // extensional equality type
    | El t           // Every element of the universe is a type
    | T / t          // quotient type (t an Ω-valued relation)
    | Ω              // universe of mere propositions
    | Prf t          // decoding of a proposition (Ω's El; deliberately not
                     //   written El: it shares none of El's rules — not
                     //   structural, not injective, no decoding computation)

// element
t ::= x [e˲]         // element in the signature context
    | ☐ᵢ             // i-th element in the typing context
    | λ t            // dependent product type introduction
    | t t            // dependent product type elimination
    | t , t          // dependent sum type introduction
    | t .π₁          // dependent sum type elimination (1)
    | t .π₂          // dependent sum type elimination (2)
    | 𝟘              // element of the universe
    | 𝟙              // element of the universe
    | ℕ              // element of the universe
    | t → t          // element of the universe (encodes Π)
    | t ⨯ t          // element of the universe (encodes Σ)
    | t ≡ t ∈ t      // element of the universe
    | t / t          // element of the universe (encodes quotient)
    | 𝟘-elim t
    | ()             // the only element of 𝟙
    | Z
    | S t
    | ℕ-elim t t t
    | Refl           // reflexive equality proof
    | class t        // quotient type introduction
    | quot-elim t t  // quotient type elimination
    | ∥T∥            // squash: proposition from an arbitrary type (an element
                     //   form embedding a type — the converse direction of El)
    | ⋆              // the canonical proof of a true proposition

// (type) telescope
Δ ::= ε | T ◁ Δ

// (element) spine
ē ::= · | e, ē

///////// Conventions: how to read the rules /////////

The rules below are presented COMPACTLY. Each convention comes with its
mechanical expansion, so the fully explicit form of every rule is
recoverable without judgement calls. (The previous fully-explicit
presentation additionally carried, with every rule, an argument-labelling
scheme consumed by the since-removed .rules derivation checker; that
interface lives on in git history only.)

* AMBIENT SIGNATURE. Every judgement is relative to a signature Σ,
  presupposed well-formed. The Σ prefix and the premise `Σ sig` are
  omitted everywhere; rules that inspect or extend Σ (the sig rules,
  the x[e˲] rules) name it explicitly. Expansion: prefix every
  judgement with `Σ ⊦`/`Σ Γ ⊦` as appropriate and add `Σ sig` as the
  first premise of every rule.

* PRESUPPOSITIONS. Each judgement form PRESUPPOSES the well-formedness
  of its parts, as listed in the judgement-form table below. A rule
  omits every premise that lies in the presupposition CLOSURE of its
  retained premises and its conclusion (the closure: start from the
  retained premises and the conclusion, add their presuppositions, and
  close transitively). Expansion: add the closure back as explicit
  premises — this recovers the previous exhaustive style, where e.g.
  `Γ ᐅ A ⊦ f : B` was always accompanied by `Γ ctx`, `Γ ⊦ A type` and
  `Γ ᐅ A ⊦ B type`. Premises NOT in the closure are never omitted: in
  particular eliminator motives, the middle subject of a transitivity,
  and the data of the coercion rules are genuine inputs and always
  appear.

* GROUPED CONCLUSIONS. A rule with several conclusions below the line
  abbreviates one rule per conclusion (same premises). A conclusion
  listing several subjects separated by commas (e.g.
  `Γ ⊦ 𝟘, 𝟙, ℕ, 𝕌 type`) abbreviates one rule per subject.

* EQUIVALENCE (PER) RULES. Each of the seven equality judgements —

    Γ₀ ≐ Γ₁ ctx                 (contexts)
    σ₀ ≐ σ₁ : Γ ⇒ Δ             (substitutions)
    e˲₀ ≐ e˲₁ : Γ ⇒ Δ norm      (normal substitutions)
    Γ ⊦ A₀ ≐ A₁ type            (types)
    Γ ⊦ a₀ ≐ a₁ : A             (elements)
    Γ ⊦ Δ₀ ≐ Δ₁ tel             (telescopes)
    Γ ⊦ ē₀ ≐ ē₁ : Δ             (element lists)

  — is governed by three rules adopted once here and not repeated per
  class. Writing J for the well-formedness form and J⁼ for the
  equality form of a class:

    J(a)              J⁼(a₀ ≐ a₁)          J⁼(a₀ ≐ a₁)   J⁼(a₁ ≐ a₂)
    ----------(refl)  -----------(sym)     ------------------------(trans, via a₁)
    J⁼(a ≐ a)         J⁼(a₁ ≐ a₀)          J⁼(a₀ ≐ a₂)

  (transitivity's middle subject a₁, with J(a₁), is an input of the
  rule). Instances are named ctx-refl, ctx-sym, ctx-trans, sub-refl,
  ..., sp-trans. Consequently the pointwise equality rules for
  constants and atoms (ε ≐ ε ctx, id ≐ id, ↑ ≐ ↑, · ≐ ·,
  x[e˲] ≐ x[e˲], ...) are refl instances and are not stated.

* DEFINITIONAL EQUALITY. A rule concluding J ≜ K asserts the
  corresponding ≐-judgement and additionally marks it as a computation
  step, oriented left to right. Its presuppositions are those of the
  underlying ≐ form.

* NAMES. Every rule carries a canonical name on its inference line,
  following one homogeneous scheme — <class>-<former>-<kind> — where
  the class is the judgement class (ctx, sub, sub-norm, ty, el, code,
  tel, sp), the former names the connective or constructor, and the
  kind distinguishes introduction (i), elimination (e), computation
  (beta), uniqueness (eta), congruence (cong), injectivity (inj),
  substitution action (sub), and coercion (coe). These names are the
  ones docs/NovaKernel.txt and docs/NovaElaboration.txt cite; there
  are no synonyms.

///////// Judgement forms and their presuppositions /////////

  Form                         Presupposes
  --------------------------   ------------------------------------
  Σ sig                        —
  Γ ctx                        —
  Γ₀ ≐ Γ₁ ctx                  Γ₀ ctx;  Γ₁ ctx
  σ : Γ ⇒ Δ                    Γ ctx;  Δ ctx
  σ₀ ≐ σ₁ : Γ ⇒ Δ              σ₀ : Γ ⇒ Δ;  σ₁ : Γ ⇒ Δ
  e˲ : Γ ⇒ Δ norm              Γ ctx;  Δ ctx
  e˲₀ ≐ e˲₁ : Γ ⇒ Δ norm       e˲₀ : Γ ⇒ Δ norm;  e˲₁ : Γ ⇒ Δ norm
  Γ ⊦ A type                   Γ ctx
  Γ ⊦ A₀ ≐ A₁ type             Γ ⊦ A₀ type;  Γ ⊦ A₁ type
  Γ ⊦ a : A                    Γ ⊦ A type
  Γ ⊦ a₀ ≐ a₁ : A              Γ ⊦ a₀ : A;  Γ ⊦ a₁ : A
  Γ ⊦ Δ tel                    Γ ctx
  Γ ⊦ Δ₀ ≐ Δ₁ tel              Γ ⊦ Δ₀ tel;  Γ ⊦ Δ₁ tel
  Γ ⊦ ē : Δ                    Γ ⊦ Δ tel
  Γ ⊦ ē₀ ≐ ē₁ : Δ              Γ ⊦ ē₀ : Δ;  Γ ⊦ ē₁ : Δ

A context extension Γ ᐅ A presupposes Γ ctx and Γ ⊦ A type, so a
premise stated under Γ ᐅ A carries A's well-formedness with it (and
likewise for iterated extensions).

--------- (sig-empty)
ε sig

Σ Γ ⊦ a : A
x ∉ Σ
--------------------- (sig-def)
Σ (Γ ⊦ x ≔ a : A) sig

Σ Γ ⊦ A type
x ∉ Σ
---------------------- (sig-ty-def)
Σ (Γ ⊦ x ≔ A type) sig

Σ Γ ⊦ 𝒮 qsig               // 𝒮 a well-formed QIIT signature over Γ
names(𝒮) ∩ Σ = ∅          // every sort/constructor name of 𝒮 is fresh
--------------------- (sig-qiit)
Σ (Γ ⊦ qiit 𝒮) sig
// The entry adds each declared name of 𝒮 to Σ, referenced as x[e˲]
// exactly like any other signature symbol. The judgement `𝒮 qsig` and
// what the entry licenses are given in "Quotient inductive-inductive
// types" below.

--------- (ctx-empty)
ε ctx

Γ ⊦ A type
----------- (ctx-ext)
Γ ᐅ A ctx

Γ₀ ≐ Γ₁ ctx
Γ₁ ⊦ A₀ ≐ A₁ type

///////// Rules (ctx substitution) /////////

Γ ctx
------------- (sub-empty)
· : Γ ⇒ ε

σ : Γ ⇒ ε
------------- (sub-empty-unique)
σ ≐ · : Γ ⇒ ε

σ : Γ₀ ⇒ Γ₁
Γ₀ ⊦ t : A[σ]
---------------------- (sub-ext)     // A the type over Γ₁ being extended by
(σ, t) : Γ₀ ⇒ Γ₁ ᐅ A

σ : Γ₀ ⇒ Γ₁
τ : Γ₁ ⇒ Γ₂
------------------- (sub-comp, via Γ₁)
τ ∘ σ : Γ₀ ⇒ Γ₂

Γ ctx
------------- (sub-id)
id : Γ ⇒ Γ

Γ ⊦ A type
---------------- (sub-wk)
↑ : Γ ᐅ A ⇒ Γ

------------------ (sub-id-empty)
id ≐ · : ε ⇒ ε

Γ ⊦ A type
------------------------------ (sub-eta) // admissible by meta-level induction
↑, ☐₀ ≐ id : Γ ᐅ A ⇒ Γ ᐅ A

σ : Γ₀ ⇒ Γ₁
------------------------ (sub-id-pre)
σ ∘ id ≐ σ : Γ₀ ⇒ Γ₁

σ : Γ₀ ⇒ Γ₁
------------------------ (sub-id-post)
id ∘ σ ≐ σ : Γ₀ ⇒ Γ₁

σ₁₀ : Γ₁ ⇒ Γ₀
σ₂₁ : Γ₂ ⇒ Γ₁
σ₃₂ : Γ₃ ⇒ Γ₂
--------------------------------------------------- (sub-assoc)
σ₁₀ ∘ (σ₂₁ ∘ σ₃₂) ≐ (σ₁₀ ∘ σ₂₁) ∘ σ₃₂ : Γ₃ ⇒ Γ₀

σ : Γ₀ ⇒ Γ₁
Γ₀ ⊦ t : A[σ]
---------------------------- (sub-wk-ext) // weakening cancels a just-added extension
↑ ∘ (σ, t) ≐ σ : Γ₀ ⇒ Γ₁

σ : Γ₀ ⇒ ε
---------------------- (sub-empty-comp) // admissible
· ∘ σ ≐ · : Γ₀ ⇒ ε

τ : Γ₀ ⇒ Γ₁
σ : Γ₁ ⇒ Γ₂
Γ₁ ⊦ t : A[σ]
------------------------------------------ (sub-ext-post) // admissible
(σ, t) ∘ τ ≐ (σ ∘ τ, t[τ]) : Γ₀ ⇒ Γ₂ ᐅ A

σ : Γ₀ ⇒ Γ₁
Γ₁ ⊦ A type
------------------------------------- (sub-lift) // natural substitution (admissible)
σ⁺ ≜ (σ ∘ ↑, ☐₀) : Γ₀ ᐅ A[σ] ⇒ Γ₁ ᐅ A

σ : Γ₀ ⇒ Γ₁
Γ₀ ⊦ t : A[σ]
τ : Γ₀ ⇒ Γ₁ ᐅ A
↑ ∘ τ ≐ σ : Γ₀ ⇒ Γ₁
Γ₀ ⊦ ☐₀[τ] ≐ t : A[↑ ∘ τ]
---------------------------- (sub-ext-unique) // admissible
(σ, t) ≐ τ : Γ₀ ⇒ Γ₁ ᐅ A
∎ (=>) τ ≐ id ∘ τ ≐ (↑, ☐₀) ∘ τ ≐ ↑ ∘ τ, ☐₀[τ] ≐ σ, t
  (<=)
      σ ≐ ↑ ∘ (σ, t) ≐ ↑ ∘ τ
      t ≐ ☐₀[σ, t] ≐ ☐₀[τ] ∎

σ₀ ≐ σ₁ : Γ₀ ⇒ Γ₁
τ₀ ≐ τ₁ : Γ₁ ⇒ Γ₂
------------------------------- (sub-comp-cong, via Γ₁)
τ₀ ∘ σ₀ ≐ τ₁ ∘ σ₁ : Γ₀ ⇒ Γ₂

σ₀ ≐ σ₁ : Γ₀ ⇒ Γ₁
Γ₀ ⊦ t₀ ≐ t₁ : A[σ₁]
--------------------------------- (sub-ext-cong)
(σ₀, t₀) ≐ (σ₁, t₁) : Γ₀ ⇒ Γ₁ ᐅ A

Γ₀ ≐ Γ₁ ctx
σ : Γ₀ ⇒ Δ
--------------- (sub-coe-dom)
σ : Γ₁ ⇒ Δ

Δ₀ ≐ Δ₁ ctx
σ : Γ ⇒ Δ₀
--------------- (sub-coe-cod)
σ : Γ ⇒ Δ₁

Γ ≐ Γ' ctx
σ ≐ τ : Γ ⇒ Δ
------------------ (sub-eq-coe-dom)
σ ≐ τ : Γ' ⇒ Δ

Δ ≐ Δ' ctx
σ ≐ τ : Γ ⇒ Δ
------------------ (sub-eq-coe-cod)
σ ≐ τ : Γ ⇒ Δ'

///////// Rules (normal substitution) /////////

Γ ctx
------------------ (sub-norm-empty)
· : Γ ⇒ ε norm

e˲ : Γ ⇒ ε norm
----------------------- (sub-norm-empty-unique)
e˲ ≐ · : Γ ⇒ ε norm

e˲ : Γ₀ ⇒ Γ₁ norm
Γ₀ ⊦ t : A[e˲]
------------------------------ (sub-norm-ext)   // A the type over Γ₁ being extended by
(e˲, t) : Γ₀ ⇒ Γ₁ ᐅ A norm

e˲₀ ≐ e˲₁ : Γ₀ ⇒ Γ₁ norm
Γ₀ ⊦ t₀ ≐ t₁ : A[e˲₁]
---------------------------------------- (sub-norm-ext-cong)
(e˲₀, t₀) ≐ (e˲₁, t₁) : Γ₀ ⇒ Γ₁ ᐅ A norm

e˲ : Γ₀ ⇒ Γ₁ norm
------------------- (sub-norm-embed) // a normal substitution is a substitution
e˲ : Γ₀ ⇒ Γ₁

e˲ : Γ₀ ⇒ Γ₁ norm
σ : Δ ⇒ Γ₀
------------------------ (sub-norm-comp, via Γ₀) // defined by meta-level induction:
e˲ ∘ σ : Δ ⇒ Γ₁ norm
    · ∘ σ ≜ ·
    (e˲, t) ∘ σ ≜ (e˲ ∘ σ, t[σ])

e˲₀ ≐ e˲₁ : Γ₀ ⇒ Γ₁ norm
σ : Δ ⇒ Γ₀
----------------------------------- (sub-norm-comp-cong, via Γ₀)
e˲₀ ∘ σ ≐ e˲₁ ∘ σ : Δ ⇒ Γ₁ norm

Γ₀ ≐ Γ₁ ctx
e˲ : Γ₀ ⇒ Δ norm
-------------------- (sub-norm-coe-dom)
e˲ : Γ₁ ⇒ Δ norm

Δ₀ ≐ Δ₁ ctx
e˲ : Γ ⇒ Δ₀ norm
----------------------- (sub-norm-coe-cod)
e˲ : Γ ⇒ Δ₁ norm

Γ ≐ Γ' ctx
e˲ ≐ t˲ : Γ ⇒ Δ norm
------------------------- (sub-norm-eq-coe-dom)
e˲ ≐ t˲ : Γ' ⇒ Δ norm

Δ ≐ Δ' ctx
e˲ ≐ t˲ : Γ ⇒ Δ norm
------------------------- (sub-norm-eq-coe-cod)
e˲ ≐ t˲ : Γ ⇒ Δ' norm

// El-decoding: El of a code computes to the type it encodes.

Γ ctx
------------------------------------------------ (ty-el-zero, ty-el-one, ty-el-nat)
Γ ⊦ El 𝟘 ≜ 𝟘 type,   El 𝟙 ≜ 𝟙 type,   El ℕ ≜ ℕ type

Γ ⊦ A : 𝕌
Γ ᐅ El A ⊦ B : 𝕌
---------------------------------- (ty-el-pi)
Γ ⊦ El (A → B) ≜ El A → El B type

Γ ⊦ A : 𝕌
Γ ᐅ El A ⊦ B : 𝕌
---------------------------------- (ty-el-sigma)
Γ ⊦ El (A ⨯ B) ≜ El A ⨯ El B type

Γ ⊦ a₀ : El A
Γ ⊦ a₁ : El A
--------------------------------------------- (ty-el-eq)
Γ ⊦ El (a₀ ≡ a₁ ∈ A) ≜ (a₀ ≡ a₁ ∈ El A) type

Γ ⊦ A : 𝕌
Γ ᐅ El A ᐅ (El A)[↑] ⊦ R : Ω
---------------------------------- (ty-el-quot)
Γ ⊦ El (A / R) ≜ El A / R type

// Substitution action on types: A[σ] is defined by meta-level
// induction on A via the ≜-equations below.

Γ₁ ⊦ A type
σ : Γ₀ ⇒ Γ₁
------------------ (ty-sub)
Γ₀ ⊦ A[σ] type

Γ ⊦ A type
--------------------- (ty-sub-id) // true on the nose by induction on A
Γ ⊦ A[id] ≐ A type

Γ₂ ⊦ A type
σ : Γ₁ ⇒ Γ₂
τ : Γ₀ ⇒ Γ₁
------------------------------ (ty-sub-comp) // true on the nose by induction on A
Γ₀ ⊦ A[σ ∘ τ] ≐ A[σ][τ] type

σ : Γ₀ ⇒ Γ₁
------------------------------------------------------------------------- (ty-sub-atoms)
Γ₀ ⊦ 𝟘[σ] ≜ 𝟘 type,   𝟙[σ] ≜ 𝟙 type,   ℕ[σ] ≜ ℕ type,   𝕌[σ] ≜ 𝕌 type,   Ω[σ] ≜ Ω type

Γ₁ ⊦ t : 𝕌
σ : Γ₀ ⇒ Γ₁
------------------------------- (ty-sub-el)
Γ₀ ⊦ (El t)[σ] ≜ El t[σ] type

Γ₁ ⊦ p : Ω
σ : Γ₀ ⇒ Γ₁
---------------------------------- (ty-prf-sub)
Γ₀ ⊦ (Prf p)[σ] ≜ Prf p[σ] type

Γ₁ ⊦ A type
Γ₁ ᐅ A ⊦ B type
σ : Γ₀ ⇒ Γ₁
--------------------------------------- (ty-sub-pi)
Γ₀ ⊦ (A → B)[σ] ≜ A[σ] → B[σ⁺] type

Γ₁ ⊦ A type
Γ₁ ᐅ A ⊦ B type
σ : Γ₀ ⇒ Γ₁
--------------------------------------- (ty-sub-sigma)
Γ₀ ⊦ (A ⨯ B)[σ] ≜ A[σ] ⨯ B[σ⁺] type

Γ₁ ⊦ a₀ : A
Γ₁ ⊦ a₁ : A
σ : Γ₀ ⇒ Γ₁
------------------------------------------------------- (ty-sub-eq)
Γ₀ ⊦ (a₀ ≡ a₁ ∈ A)[σ] ≜ (a₀[σ] ≡ a₁[σ] ∈ A[σ]) type

Γ₁ ⊦ A type
Γ₁ ᐅ A ᐅ A[↑] ⊦ R : Ω
σ : Γ₀ ⇒ Γ₁
---------------------------------------- (ty-sub-quot)
Γ₀ ⊦ (A / R)[σ] ≜ A[σ] / R[σ⁺⁺] type

(Γ ⊦ x ≔ A type) ∈ Σ
e˲ : Γ₁ ⇒ Γ norm
σ : Γ₀ ⇒ Γ₁
----------------------------------- (ty-sub-sig-var)
Σ Γ₀ ⊦ x[e˲][σ] ≜ x[e˲ ∘ σ] type

Γ ⊦ A type
Γ ⊦ B type
Γ ⊦ t : 𝟘
------------------ (ty-zero-elim) // type equality from absurdity
Γ ⊦ A ≐ B type

Γ₀ ≐ Γ₁ ctx
Γ₀ ⊦ A type
--------------- (ty-coe-ctx)
Γ₁ ⊦ A type

Γ₀ ≐ Γ₁ ctx
Γ₀ ⊦ A ≐ B type
------------------- (ty-eq-coe-ctx)
Γ₁ ⊦ A ≐ B type

Δ ⊦ A₀ ≐ A₁ type
σ₀ ≐ σ₁ : Γ ⇒ Δ
------------------------------ (ty-sub-cong)
Γ ⊦ A₀[σ₀] ≐ A₁[σ₁] type

Δ ⊦ A₀ ≐ A₁ type
σ : Γ ⇒ Δ
------------------------------ (ty-sub-cong-fix) // admissible: specialize via sub-refl
Γ ⊦ A₀[σ] ≐ A₁[σ] type

Γ ⊦ A₀ ≐ A₁ type
Γ ᐅ A₁ ⊦ B₀ ≐ B₁ type
------------------------------- (ty-pi-cong)
Γ ⊦ A₀ → B₀ ≐ A₁ → B₁ type

Γ ⊦ A₀ ≐ A₁ type
Γ ᐅ A₁ ⊦ B₀ ≐ B₁ type
------------------------------- (ty-sigma-cong)
Γ ⊦ A₀ ⨯ B₀ ≐ A₁ ⨯ B₁ type

Γ ⊦ A₀ ≐ A₁ type
Γ ᐅ A₁ ᐅ A₁[↑] ⊦ R₀ ≐ R₁ : Ω

///////// Type constructor injectivity /////////
//
// The congruence rules above run downward: equal components give equal
// composites. The rules below run upward: equal composites give equal
// components. They are NOT derivable from the rest of the theory — in
// the plain set-theoretic model (types as sets, function types as sets
// of graphs) the hypothesis h : ((𝟙 → 𝟘) ≡ (ℕ → 𝟘) ∈ 𝕌) is satisfiable
// (both function spaces are the empty set), yet 𝟙 ≐ ℕ is refuted, so
// before these rules the composite equality was derivable in a context
// where the component equality was not. Adding them is a semantic
// commitment, and it is the one this file's preface already makes:
// semantics is assigned via evaluation and canonical forms, i.e. the
// type system is an inductively defined PER on canonical forms, where
// two Π-types are equal BY DEFINITION exactly when their domains are
// equal and their codomains are equal on related arguments — and
// likewise for the other formers. Under that semantics these rules are
// sound; models that collapse structurally distinct types (the
// set-theoretic one above) are hereby excluded. A concrete consequence:
// a context hypothesizing (𝟙 → 𝟘) ≡ (ℕ → 𝟘) ∈ 𝕌 is now INCONSISTENT
// (𝟙 ≐ ℕ gives Z ≐ S Z : ℕ via el-one-prop and coercion, and a ℕ-elim
// discriminator into 𝕌 turns that into an inhabitant of 𝟘).
//
// Notes:
//  * The codomain/relation components are concluded UNDER the domain —
//    this is what keeps the rules compatible with empty-domain
//    collapses (𝟘 → 𝟙 ≐ 𝟘 → ℕ is harmless: under a 𝟘-hypothesis the
//    component 𝟙 ≐ ℕ is derivable by absurdity anyway).
//  * Quotient relations are Ω-valued, so the relation components are
//    compared at Ω, where judgemental equality IS logical equivalence
//    (code-prop-eq). Quotient type equality therefore coincides with
//    NuPRL's iff-based one — obtained through structural rules rather
//    than a bespoke clause. This does not compromise 𝕌's structural
//    discipline: 𝕌 is structural in its FORMERS and was always
//    extensional in its element slots (code-eq compares its endpoint
//    slots by ≐, which reflection already makes extensional); an
//    Ω-slot in code-quot is the same pattern.
//  * class stays NON-injective: class a ≐ class b : A / R does not
//    entail a ≐ b — that is the entire point of quotients.
//  * Prf and ∥-∥ likewise have NO injectivity rules: Ω is the
//    anti-structural universe, compared by inhabitation alone (see
//    the Ω block in the element rules).
//  * No-confusion (a Π-type is never equal to ℕ, a Σ-type, ...) is NOT
//    expressible as a rule of this positive inference system, and in
//    inconsistent contexts it is false. It remains a meta-property of
//    consistent contexts under the canonical-forms semantics.
//  * S-injectivity and pair-injectivity need no rules: they are already
//    derivable (congruence with a ℕ-elim predecessor, respectively the
//    projections).

// Ω: squash, proof irrelevance, propositional extensionality.
//
// Ω is a second universe, of mere propositions; its equality
// discipline is the mirror image of 𝕌's. 𝕌's codes are compared
// STRUCTURALLY (the injectivity block); Ω's codes are compared by
// INHABITATION alone (code-prop-eq). Each discipline is sound only on
// its own side of the fence, so the universes must not mix: there is
// no code for Ω or for Prf p in 𝕌, and no Ω analogue of any
// inj rule.
//
// Notes:
//  * Realizer irrelevance is FORCED, not chosen: code-prop-eq +
//    ty-prf-cong + el-ty-coe move an element between the decodings of
//    iff-equal props UNCHANGED, which is sound only if those decodings
//    have literally the same canonical forms. So Prf p never exposes
//    the squashed proofs: its one canonical form is ⋆ (cf. NuPRL's
//    Ax), and el-prf-prop equates all members. Consequently there is
//    no Prf-beta — Prf ∥A∥ does NOT reduce to A — and no
//    code-squash-inj / ty-prf-inj: ∥𝟙∥ ≐ ∥Z ≡ Z ∈ ℕ∥ : Ω holds by
//    code-prop-eq while the squashees are structurally distinct. Ω
//    adds no computation rules beyond substitution actions; the
//    preface's normalization story is unchanged.
//  * Squash is the only way in: ∥-∥ takes an arbitrary TYPE, not a
//    𝕌-code, so the connectives are signature definitions, not rules —
//      ⊤ ≔ ∥𝟙∥,  ⊥ ≔ ∥𝟘∥,  p ∧ q ≔ ∥Prf p ⨯ (Prf q)[↑]∥,
//      p ⊃ q ≔ ∥Prf p → (Prf q)[↑]∥,  ∀ over A ≔ ∥A → Prf p∥,
//      ∃ over A ≔ ∥A ⨯ Prf p∥,  squashed equality ≔ ∥a ≡ b ∈ A∥
//    — and every definable prop is ∥-∥-headed, so the eliminators
//    below lose no generality; derived intro/elim principles come
//    from el-squash-i / el-squash-e-* over the underlying former.
//  * Elimination goes only into equations and props: a squashed
//    hypothesis may be unsquashed exactly when the goal cannot
//    observe WHICH proof was used — equational goals (judgements do
//    not consult realizers) and propositional goals (the realizer is
//    ⋆ either way). el-squash-e-eq is not subsumed by
//    el-squash-e-prf: it reaches equations at LARGE types (e.g.
//    a₀ ≐ a₁ : 𝕌), which have no prop code to route through. There is
//    deliberately NO eliminator into arbitrary types — el-prf-prop
//    would force it constant, and it would refute realizer
//    irrelevance in the model. The eliminators need no congruence
//    rules: their conclusions are equations, respectively ⋆-typings
//    covered by el-prf-prop.
//  * IMPREDICATIVITY. ∥-∥ squashes arbitrary types, including
//    quantifications over Ω itself and over 𝕌. This is sound
//    because the candidate denotations of props form a FIXED
//    two-point lattice — ∅ and {(⋆,⋆)} — that does not grow with the
//    quantification domain: a universally quantified prop is an
//    infimum in that lattice, realized uniformly by λ ⋆ (precedent:
//    the PER models of the Calculus of Constructions). The
//    restrictions above are the license for this; each blocks a known
//    paradox:
//      - proof irrelevance blocks Girard/Hurkens: nothing can be
//        stored in a prop and retrieved for diagonalization (in
//        particular, Church encodings through Ω are sterile — no
//        data can be smuggled past the size restrictions);
//      - no elimination into arbitrary types blocks unique choice /
//        description, and with it the quotient+choice collapses
//        (Chicli–Pottier–Simpson);
//      - no Ω-code in 𝕌 blocks Reynolds/Cantor: A → Ω stays
//        large, so no type contains its own powerset. Note that
//        prf-codes themselves are DERIVABLE from the Ω-valued
//        quotient slot: prf r ≜ (class Z ≡ class (S Z) ∈ ℕ / r̂), a
//        𝕌-code whose decoding is inhabited iff r — el-quot-eq plus
//        coercion one way, effectivity along ∥x ≡ y ∈ ℕ∥ ∨ r the
//        other. So 𝕌's element slots already contain Ω up to iff,
//        and the load-bearing prohibition is exactly the first
//        clause: no code for Ω ITSELF. Propositions and powersets
//        embed only into the CODES of 𝕌 — a large collection — never
//        into the elements of a small type: equality at 𝕌 has no
//        code (code-eq needs an El-ambient), El A → 𝕌 is large, and
//        quotient elements cannot store a proposition (coherence
//        forces eliminators out of 𝟙/r̂-style types constant).
//    Payoff: least relations by intersection — e.g. an equivalence
//    closure r⁺ of an arbitrary relation r, defined by quantifying
//    over all Ω-valued relations containing r — with no inductive
//    machinery. And since code-quot takes its relation at Ω rather
//    than at 𝕌, A / r⁺ is still a 𝕌-code: quotients by generated
//    congruences stay small.
//  * Consequences for quotients (whose relation slot is Ω-valued —
//    see ty-quot):
//      1. Mutually implied relations give EQUAL quotient types:
//         code-prop-eq under Γ ᐅ A ᐅ A[↑] gives R₀ ≐ R₁ : Ω, then
//         ty-quot-cong; dually ty-quot-inj returns only iff-content.
//         A proof-relevant presentation is recovered as A / ∥R∥.
//      2. Effectivity: for R : Ω over Γ ᐅ A ᐅ A[↑], an equivalence
//         at squash level, class a ≐ class b : A / R implies
//         Prf R[id, a, b] inhabited — via quot-elim at the constant
//         motive Ω with f ≔ R[id, a, ☐₀], coherence discharged by
//         code-prop-eq from symmetry/transitivity, then el-quot-beta,
//         ty-prf-cong and el-ty-coe on ⋆. Combined with r⁺ above this
//         characterizes quotient equality for ARBITRARY relations.
//      3. Squashed equalities reflect: from s : Prf ∥a₀ ≡ a₁ ∈ B∥,
//         el-squash-e-eq + el-reflect give a₀ ≐ a₁ : B — squashing
//         loses no equational content.
//  * SEMANTICS. ⟦Prf p⟧ = {(t,t') | t ⇓ ⋆ and t' ⇓ ⋆} if p's squashee
//    is inhabited, ∅ otherwise; ∥A∥ ~ ∥B∥ : Ω iff A and B are
//    equi-inhabited. code-prop-eq holds on the nose (iff-equal props
//    have IDENTICAL decodings); el-squash-e-* are validated by
//    instantiating their premise at any closed witness — the
//    conclusion never consults which one. Model note: the prop layer
//    cannot be built by the same stagewise induction as the rest of
//    the type system (the Π-over-Ω clause consults Ω's full
//    domain, non-monotonically); it is instead given IN ADVANCE — the
//    fixed lattice above, with prop-truth defined against the full
//    type system. A two-layer construction, as in the PER models of
//    CC. The Ω-valued quotient slot adds no further impredicative
//    dependency: the quotient clause consumes Ω-truth POINTWISE
//    (⟦El (A / R)⟧ is ⟦El A⟧ coarsened by the truth of R at each
//    pair), so quotient codes stay small however impredicative their
//    relation — propositional resizing, in HoTT terms, which the PER
//    model validates.

///////// Quotient inductive-inductive types (signatures) /////////
//
// The formers ℕ and quotient each add ONE type. QIITs add a SCHEME: a
// family of mutually-defined, possibly index-dependent sorts, generated
// freely by point constructors and quotiented by equation constructors
// — the inductive-inductive quotient types of Altenkirch–Kaposi, whose
// "theory of signatures" Nova's Σ already resembles. The scheme
// SUBSUMES ℕ and (/) (each is a one-line signature), and covers indexed
// inductive types (well-founded trees included) and quotient inductive
// types generally; ℕ and (/) are retained for now.
//
// THE EXTENSIONAL PAYOFF. Under equality reflection (with Ω for
// proof-irrelevance) every type is a set: no higher paths, no coherence
// tower, no transport. A path constructor is therefore an equation
// IMPOSED judgementally (via el-reflect), and the eliminator's path
// premises collapse to WELL-DEFINEDNESS conditions — precisely
// quot-elim's f⁼ premise, one per equation, with no apd/transport.
// This degeneration is what lets the scheme be POSTULATED precisely
// rather than through a tower of coherences (contrast the intensional
// HIIT signatures, which need the full apparatus).

// SIGNATURES. A QIIT signature 𝒮 (over the entry's parameter context Γ)
// is an ORDERED context of declarations, each free to reference those
// before it — that ordering is what makes the scheme
// inductive-INDUCTIVE (a later sort may be indexed by an earlier one):
//
//   𝒮 ::= ⬦                          // empty
//       | 𝒮, (𝕤 : Δ ⇛ U)            // SORT: a type family indexed by Δ
//       | 𝒮, (𝕔 : Θ ⇛ 𝕤 ē)          // POINT constructor into 𝕤 at ē
//       | 𝒮, (𝕔 : Θ ⇛ l ≡ r ∈ 𝕤 ē)  // EQUATION (path) constructor
//
//   ⇛ separates a telescope of arguments from a result (a
//   signature-level notation, not Nova's →). Δ (a sort's index
//   telescope) and Θ (a constructor's argument telescope) have entries
//   each of which is either
//     * EXTERNAL — a type mentioning NO sort of 𝒮 (a parameter or an
//       index drawn from an already-existing type, e.g. an external ℕ);
//       or
//     * RECURSIVE (in Θ only) — Ξ ⇛ 𝕤ⱼ w̄, a function from an external
//       telescope Ξ (no sorts) into a sort 𝕤ⱼ at indices w̄: the SOLE
//       strictly-positive recursive shape. A sort never occurs left of
//       a →, nor under any former other than this.
//   ē, w̄ are index spines; l, r are terms of sort 𝕤 ē built from Θ's
//   variables and the preceding POINT constructors (free-algebra terms).
//
//   Strict positivity is thus STRUCTURAL — the grammar cannot write a
//   non-positive argument, exactly as in the theory of signatures (U is
//   not closed under the recursive arrow). See the relaxation note.

// WELL-FORMEDNESS. Γ ⊦ 𝒮 qsig is defined by meta-level recursion over
// the context 𝒮: ⬦ is well-formed; a sort extends 𝒮 with a fresh
// type-family symbol (Δ checked as a telescope over Γ and the sorts so
// far); a point constructor checks Θ against the positivity grammar and
// its result indices ē; an equation constructor additionally checks
// that l, r are terms of the stated sort. names(𝒮) collects the
// declared sort/constructor names (all required fresh by sig-qiit).

// IDENTITY (structural, with a same-name shortcut). A QIIT sort's
// equality is STRUCTURAL — homogeneous with every other former in this
// file. Two sorts are equal when their SIGNATURES are equal, compared
// INTENSIONALLY: as finite syntax modulo α-renaming of the signature's
// own sort/constructor binders (and of ordinary bound variables),
// exactly as universe codes are compared. The self-reference of an
// inductive-inductive signature is a BOUND reference inside the finite
// signature, so the comparison is finite and iso-recursive — it never
// unfolds the fixpoint into its carrier (F[μF]) and needs no
// equirecursive/coinductive machinery. (α-signature-equality is finer
// than initial-algebra isomorphism — it distinguishes constructor
// reorderings — but it is SOUND, and choosing a syntactic granularity
// over the semantic one is the same commitment the code-injectivity
// block already makes for the base formers: models that collapse
// structurally-distinct types are excluded.)
//
// SAME-NAME SHORTCUT (a conversion-procedure discipline, not a rule).
// Names are fresh (sig-qiit), so a name identifies its declaration
// uniquely. When both sides reference the SAME name,
//       x[e˲] ≐ x[e˲']   is concluded from   e˲ ≐ e˲'
// with NO unfolding — same name ⟹ same signature ⟹ structural
// congruence. The procedure MUST take this positive step BEFORE the
// sides are normalized: eager β/δ (which unfolds x[e˲] to its signature
// with e˲ pushed inside — ty-sig-beta) loses the shared name and forces
// the full, far costlier, signature walk. This is the standard
// rigid-rigid-before-δ discipline, which QIITs make mandatory rather
// than merely economical; in the certificate kernel the same-name
// congruence must be verifiable before normalization unfolds the
// reference. Different names, or a failed e˲ match, fall through to
// δ-unfolding and structural signature comparison — that fallback is
// what keeps the equality COMPLETE (two differently-named but α-equal
// signatures are still equal). Omitting the fallback is only ever
// incomplete, NEVER unsound: a missed equality is a spurious obligation,
// not a bad acceptance.
//
// Consequently the theory is UNIFORMLY structural, QIITs included, so
// (/) is a genuine INLINE instance — A / R is
//     qiit (𝕢 : U; cls : (A) ⇛ 𝕢;
//           eq : (a b : A)(_ : Prf R) ⇛ cls a ≡ cls b ∈ 𝕢)
// — and the primitive (/) is kept for convenience, not necessity. (The
// nominal/generative alternative, in which QIITs would be the one
// non-structural former and (/) could not be reduced to one, was
// rejected for that disharmony.)

// WHAT THE ENTRY LICENSES. Every symbol of 𝒮 is referenced as x[e˲],
// with e˲ substituting the parameters Γ together with the sort's
// indices resp. the constructor's arguments (the declaration context is
// Γ extended by Δ resp. Θ). The three rules below are parameterized by
// membership in 𝒮, exactly as ty-sig-var/el-sig-var are parameterized
// by membership in Σ; the eliminator that follows is genuinely
// schematic and stated by meta-recursion.

// Formation — for each sort: a postulated type family. A sort has no
// ι/β-reduction of its own (its only computation is the eliminator's β);
// its equality is structural per IDENTITY above, short-circuited by the
// same-name rule.

(Γ ⊦ qiit 𝒮) ∈ Σ      (𝕤 : Δ ⇛ U) ∈ 𝒮      e˲ : Ξ ⇒ Γ·Δ norm
-------------------------------------------------------------- (ty-qiit-sort)
Σ Ξ ⊦ 𝕤[e˲] type

// Introduction — for each point constructor: a postulated term symbol,
// computing only under the eliminator (no unfolding).

(Γ ⊦ qiit 𝒮) ∈ Σ      (𝕔 : Θ ⇛ 𝕤 ē) ∈ 𝒮      e˲ : Ξ ⇒ Γ·Θ norm
--------------------------------------------------------------- (el-qiit-intro)
Σ Ξ ⊦ 𝕔[e˲] : 𝕤 ē[e˲]

// Path — for each equation constructor: a postulated proof, hence — by
// el-reflect — an IMPOSED ≐-equation.

(Γ ⊦ qiit 𝒮) ∈ Σ      (𝕔 : Θ ⇛ l ≡ r ∈ 𝕤 ē) ∈ 𝒮      e˲ : Ξ ⇒ Γ·Θ norm
--------------------------------------------------------------------- (el-qiit-path)
Σ Ξ ⊦ 𝕔[e˲] : (l[e˲] ≡ r[e˲] ∈ 𝕤 ē[e˲])
// whence  Σ Ξ ⊦ l[e˲] ≐ r[e˲] : 𝕤 ē[e˲]  by el-reflect

// ELIMINATION (induction) + COMPUTATION. The dependent eliminator is
// determined by 𝒮, by meta-recursion — the standard displayed-algebra
// (-ᴰ) and section (-ˢ) translations, which extensionality makes
// concrete:
//   * MOTIVES: for each sort (𝕤 : Δ ⇛ U), a family
//         C_𝕤  over  Γ·Δ ᐅ 𝕤[…]        (over the indices and an
//                                       inhabitant of the sort).
//   * METHODS: for each point constructor (𝕔 : Θ ⇛ 𝕤 ē), a term
//         building  C_𝕤(ē, 𝕔 args)  from Θ's arguments together with,
//         for each RECURSIVE argument (Ξ ⇛ 𝕤ⱼ w̄), its induction
//         hypothesis  (Ξ → C_𝕤ⱼ(w̄, that argument applied)).   (-ᴰ of Θ)
//   * COHERENCE (well-definedness): for each equation constructor
//         (𝕔 : Θ ⇛ l ≡ r ∈ 𝕤 ē), the premise that the method-images of
//         the two sides agree,
//             ⟦l⟧ ≐ ⟦r⟧ : C_𝕤(ē, l)          (extensional; no transport)
//         where ⟦·⟧ sends a free-algebra term to its value under the
//         methods. This is quot-elim's f⁼, one per equation.
//   Given all motives, methods and coherence premises, for each sort:
//         elim_𝕤 : (v̄ : Δ)(x : 𝕤 v̄) → C_𝕤(v̄, x)              (section)
//   and, for each point constructor, the β-rule:
//         elim_𝕤 (𝕔 args) ≜ method_𝕔(args, elim_ on the recursive args)
//   Equation constructors have NO β-rule: a proof of an equality
//   carries no computational content — el-reflect already consumed it.

// NOTES.
//   * SUBSUMPTION. ℕ ≡ qiit (𝕟 : U; Z : ⬦ ⇛ 𝕟; S : (𝕟) ⇛ 𝕟). The
//     quotient A / R ≡ qiit (𝕢 : U; cls : (A) ⇛ 𝕢;
//       eq : (a b : A)(_ : Prf R) ⇛ cls a ≡ cls b ∈ 𝕢). An indexed
//     inductive type (well-founded trees included) is a sorts-only
//     signature: sorts indexed by I, one point constructor per node
//     shape whose recursive arguments are the subtrees. Because QIIT
//     equality is structural (IDENTITY above), these are genuine
//     equalities, not just encodings: ℕ and (/) are kept for
//     convenience but are now DERIVABLE, each a one-line signature.
//   * RELAXATION. Strict positivity here is structural (the argument
//     grammar). It is the DECIDABLE proxy for a semantic condition: that
//     the signature's operator be monotone on the PER lattice. A future
//     revision may drop the grammar restriction in favour of a
//     monotonicity obligation stated as an ordinary premise, admitting
//     monotone-but-not-positive operators; postulated here in the
//     positive fragment only.
//   * SEMANTICS. The postulate asserts that 𝒮's INITIAL ALGEBRA exists
//     in the canonical-forms model: carriers are the constructor terms
//     quotiented by the congruence GENERATED by the equation
//     constructors, elim_𝕤 is the unique section into any displayed
//     algebra, and β holds on the nose. This is the initiality
//     commitment of Altenkirch–Kaposi–Kovács (finitary QIITs),
//     transported to the extensional PER setting where the coherence
//     tower degenerates. As with the injectivity rules, models that fail
//     initiality are hereby excluded.

// EXAMPLE (inductive-inductive: contexts and types).
//     qiit ( Con : ⬦ ⇛ U
//          ; Ty  : (Con) ⇛ U
//          ; ⋄   : ⬦ ⇛ Con
//          ; ext : (Γ : Con)(A : Ty Γ) ⇛ Con                 // Γ ▷ A
//          ; u   : (Γ : Con) ⇛ Ty Γ
//          ; pi  : (Γ : Con)(A : Ty Γ)(B : Ty (ext Γ A)) ⇛ Ty Γ )
//   Con and Ty are mutually indexed (Ty is indexed by Con); induction
//   is induction-induction — a motive for Con and a motive for Ty over
//   it, methods respecting the dependency.
//
// EXAMPLE (quotient: finite multisets over an external type A).
//     qiit ( Bag : ⬦ ⇛ U
//          ; nil : ⬦ ⇛ Bag
//          ; ins : (a : A)(m : Bag) ⇛ Bag                     // a ∷ m
//          ; swp : (a b : A)(m : Bag) ⇛ ins a (ins b m)
//                                        ≡ ins b (ins a m) ∈ Bag )
//   swp is an equation constructor; Bag's eliminator carries the
//   coherence premise that the method for ins is invariant under
//   swapping the two heads — the multiset laws, no transport.

Γ ᐅ A ⊦ f₁ : B[↑, class ☐₀]
Γ ᐅ A ᐅ A[↑] ᐅ Prf R ⊦ f₀[↑ ∘ ↑ ∘ ↑, ☐₂] ≐ f₀[↑ ∘ ↑ ∘ ↑, ☐₁] : B[↑ ∘ ↑ ∘ ↑, class ☐₂]
Γ ᐅ A ᐅ A[↑] ᐅ Prf R ⊦ f₁[↑ ∘ ↑ ∘ ↑, ☐₂] ≐ f₁[↑ ∘ ↑ ∘ ↑, ☐₁] : B[↑ ∘ ↑ ∘ ↑, class ☐₂]
Γ ᐅ A ⊦ f₀ ≐ f₁ : B[↑, class ☐₀]
Γ ⊦ q₀ ≐ q₁ : A / R
------------------------------------------------------ (el-quot-e-cong, motive B)
Γ ⊦ quot-elim f₀ q₀ ≐ quot-elim f₁ q₁ : B[id, q₁]

// Congruence rules for universe code constructors.

Γ ⊦ A₀ ≐ A₁ : 𝕌
Γ ᐅ El A₁ ⊦ B₀ ≐ B₁ : 𝕌
------------------------------- (code-pi-cong)
Γ ⊦ A₀ → B₀ ≐ A₁ → B₁ : 𝕌

Γ ⊦ A₀ ≐ A₁ : 𝕌
Γ ᐅ El A₁ ⊦ B₀ ≐ B₁ : 𝕌
------------------------------- (code-sigma-cong)
Γ ⊦ A₀ ⨯ B₀ ≐ A₁ ⨯ B₁ : 𝕌

Γ ⊦ A₀ ≐ A₁ : 𝕌
Γ ⊦ a₀ ≐ a₁ : El A₁
Γ ⊦ b₀ ≐ b₁ : El A₁
--------------------------------------------- (code-eq-cong)
Γ ⊦ (a₀ ≡ b₀ ∈ A₀) ≐ (a₁ ≡ b₁ ∈ A₁) : 𝕌

Γ ⊦ A₀ ≐ A₁ : 𝕌
Γ ᐅ El A₁ ᐅ (El A₁)[↑] ⊦ R₀ ≐ R₁ : Ω
--------------------------------------- (code-quot-cong)
Γ ⊦ A₀ / R₀ ≐ A₁ / R₁ : 𝕌

Γ ⊦ A₀ ≐ A₁ type
--------------------------- (code-squash-cong) // admissible via code-prop-eq + el-ty-coe
Γ ⊦ ∥A₀∥ ≐ ∥A₁∥ : Ω

///////// Rules (elem list) /////////

Γ ctx
------------- (sp-empty)
Γ ⊦ · : ε

Γ ᐅ A ⊦ Δ tel
Γ ⊦ e : A
Γ ⊦ ē : Δ[id, e]
---------------------- (sp-ext)
Γ ⊦ e, ē : A ◁ Δ

Γ ᐅ A ⊦ Δ tel
Γ ⊦ e₀ ≐ e₁ : A
Γ ⊦ ē₀ ≐ ē₁ : Δ[id, e₁]
--------------------------------- (sp-ext-cong)
Γ ⊦ (e₀, ē₀) ≐ (e₁, ē₁) : A ◁ Δ

Γ₁ ⊦ ē : Δ
σ : Γ₀ ⇒ Γ₁
---------------------- (sp-sub) // defined by meta-level induction on ē
Γ₀ ⊦ ē[σ] : Δ[σ]

σ : Γ₀ ⇒ Γ₁
----------------------- (sp-sub-empty)
Γ₀ ⊦ ·[σ] ≜ · : ε

Γ₁ ⊦ e : A
Γ₁ ᐅ A ⊦ Δ tel
Γ₁ ⊦ ē : Δ[id, e]
σ : Γ₀ ⇒ Γ₁
------------------------------------------------ (sp-sub-ext)
Γ₀ ⊦ (e, ē)[σ] ≜ e[σ], ē[σ] : A[σ] ◁ Δ[σ⁺]

Γ ≐ Γ' ctx
Γ ⊦ ē : Δ
--------------- (sp-coe-ctx)
Γ' ⊦ ē : Δ

Γ ⊦ Δ ≐ Δ' tel
Γ ⊦ ē : Δ
------------------ (sp-coe-tel)
Γ ⊦ ē : Δ'

Γ ≐ Γ' ctx
Γ ⊦ ē ≐ ē' : Δ
-------------------- (sp-eq-coe-ctx)
Γ' ⊦ ē ≐ ē' : Δ

Γ ⊦ Δ₀ ≐ Δ₁ tel
Γ ⊦ ē₀ ≐ ē₁ : Δ₀
-------------------- (sp-eq-coe-tel)
Γ ⊦ ē₀ ≐ ē₁ : Δ₁

Γ₁ ⊦ ē₀ ≐ ē₁ : Δ
σ₀ ≐ σ₁ : Γ₀ ⇒ Γ₁
----------------------------------- (sp-sub-cong)
Γ₀ ⊦ ē₀[σ₀] ≐ ē₁[σ₁] : Δ[σ₁]

///////// Rule name scheme /////////

Names follow <class>-<former>-<kind> uniformly (see Conventions).
The PER schema instances are ctx-refl/-sym/-trans, sub-…, sub-norm-…,
ty-…, el-…, tel-…, sp-…. All other names appear verbatim on their
rules; there are no synonyms.
