#
# This file contains a formalisation of Nova's type theory: Extensional Computational Type Theory.
# The presentation is by inference rules over a first-order grammar, and
# its OFFICIAL reading is COMPUTATIONAL, in the sense of NuPRL and
# Allen: the grammar is a prior universe of raw terms, a type is a
# PARTIAL EQUIVALENCE RELATION on them, and the one judgement of the
# theory is the equation Γ ⊦ a₀ ≐ a₁ : A — "a₀ and a₁ are related in
# A". Membership is the diagonal: Γ ⊦ a : A is notation for
# Γ ⊦ a ≐ a : A, a term being an element of a type exactly when it is
# related to itself. The setoid model below is this reading made
# precise; canonicity-style consequences are stated as
# meta-properties where they are used.
#
# THERE IS NO TYPE JUDGEMENT. Earlier presentations carried a separate
# judgement pair Γ ⊦ A type / Γ ⊦ A₀ ≐ A₁ type; both are DISSOLVED
# into the element judgement at the UNIVERSES — Γ ⊦ A₀ ≐ A₁ : 𝕌ℓ, with
# Γ ⊦ A : 𝕌ℓ its diagonal — and the type and element grammars are
# merged into ONE term sort. The universes form a CUMULATIVE TOWER
# 𝕌₀ : 𝕌₁ : 𝕌₂ : … (ℓ a natural-number literal), with the universe of
# propositions Ω below its bottom: Ω : 𝕌₁, and every proposition a 𝕌₀
# code (see THE TOWER in the type rules). There is no top: every type
# is an element of some universe, and "A is a type" everywhere below
# MEANS Γ ⊦ A : 𝕌ℓ for some ℓ. The type slot of the equality
# proposition admits the universes, so type-equality props
# (A ≡ B ∈ 𝕌ℓ) exist and type equality is reflection-complete like
# element equality (see code-eq and its SEMANTICS note in the Ω
# block).
#
# AND NO TYPING JUDGEMENT EITHER, as a primitive: the ONE judgement
# is the EQUATION Γ ⊦ a₀ ≐ a₁ : A, and Γ ⊦ a : A is NOTATION for its
# diagonal Γ ⊦ a ≐ a : A (EQUALITY, in the conventions). Every rule
# of the theory is therefore a rule about equations; the rules that
# LOOK like typing rules below are displayed in their diagonal form
# and READ in full by the DOUBLING CONVENTION — each term
# metavariable split into a left and a right instance, the conclusion
# an equation — so that the former rules ARE the congruence rules and
# nothing is stated twice. Equality REFLECTION is a rule (el-reflect:
# an inhabitant of the proposition a₀ ≡ a₁ ∈ A gives the equation)
# and INTERNALIZATION its converse (el-eq-i: the equation gives ⋆ as
# an inhabitant); the proposition internalizes the judgement, it does
# not define it. The remaining equality forms (contexts,
# substitutions, telescopes, spines) are pointwise META-DEFINITIONS
# over the one judgement, their well-formedness the diagonal.
# The setoid model interprets the judgement as the relation and the
# diagonal as membership, so typing and equality are one relation
# seen twice, never two. (The DISSOLVED NAMES table at the end of this
# file maps every retired rule name to its replacement.)
#
# Semantics is assigned by the SETOID MODEL: a type denotes a
# structural CODE together with a proof-irrelevant equivalence relation
# on the code's decoding — type equality is equality of codes, element
# equality is the relation. docs/NovaModel.txt constructs the code
# layer for the structural fragment; the relation layer is where
# quotients, Ω-truth and the QIIT congruences live (see the SEMANTICS
# notes at their rules).
#
# NOTE: well-typed terms need not normalize in an inconsistent context.
# Equality reflection makes typability hypothesis-sensitive: e.g. under
# Γ ∋ h : (A ≡ (A → A) ∈ 𝕌), the equation A ≐ A → A holds (and
# lifts to types by code-lift-eq), so
# self-application types and ω ω is well-formed at A, where ω ≜ λx. x x
# — yet ω ω has no normal form. Normalization is therefore a property of terms
# in consistent contexts only; any procedure that beta-normalizes a
# well-formed term (as the checker does when storing and comparing facts)
# may diverge under inconsistent hypotheses. This is a liveness caveat, not
# a soundness one: a non-terminating normalization never certifies a
# judgement.

//////////// Type Theory /////////////

# We have:
#  * Empty type: 𝟘
#  * Unit type: 𝟙
#  * Natural numbers type: ℕ
#  * Dependent product type: (→)
#  * Dependent sum type: (×)
#  * Non-dependent sum type: (⊎) — the disjoint union, with injections
#    inj₁/inj₂ and a dependent eliminator ⊎-elim (β on each injection,
#    uniqueness η in el-nat-eta's style). DEFINABLE as a QIIT (a
#    two-point signature — see SUBSUMPTION in the QIIT notes); retained
#    as a standalone former, like ℕ and (/)
#  * Equality proposition: (≡), Ω-valued and DEFINITIONALLY
#    reflected — the judgemental spelling ≐ is notation for its
#    ⋆-inhabitation — a prop IS its type of proofs (prop-lift);
#    proof-irrelevant by el-prf-prop (see the Ω block)
#  * Quotient type: (/), by an Ω-valued relation
#  * A cumulative tower of predicative universes: 𝕌₀ : 𝕌₁ : 𝕌₂ : … —
#    the types are exactly their elements (Γ ⊦ A : 𝕌ℓ is this
#    theory's "A is a type"); a type of one level is one of every
#    higher level (code-lift), and there is no top — see THE TOWER
#  * A universe of mere propositions: Ω (squash ∥-∥, propositional
#    extensionality) — impredicative, irrelevant, and a subuniverse of
#    the bottom of the tower: Ω : 𝕌₁, every proposition a 𝕌₀ code
#    (prop-lift), Ω itself never a 𝕌₀ code
#  * Quotient inductive-inductive types (QIITs): a SCHEME (not a single
#    former) — for each well-formed signature 𝒮 (mutually-defined,
#    possibly index-dependent sorts with point AND equation (path)
#    constructors), the sorts 𝒮.𝕤 ē as types, their constructors 𝒮.𝕔 θ,
#    the imposed path equations, and a dependent eliminator 𝒮.𝕤-elim with
#    its computation and uniqueness laws. Every rule is stated against a
#    signature (no Σ-entry; 𝒮 is carried by the formers). This subsumes ℕ,
#    (⊎) and (/) (each a one- or two-line signature), including indexed
#    inductive types
#    and quotient inductive types as special cases; its equation
#    constructors are INDUCTIVE (they may relate constructor terms across
#    indices and participate in the induction). ℕ, (⊎) and (/) are
#    retained for now.
#  * Coinductive types: a second SCHEME, dual to QIITs in its smallest
#    useful form — for each POLYNOMIAL 𝔽 (a one-hole strictly positive
#    code), the type ν 𝔽, its observation out (the eliminator), its
#    corecursor corec (the introduction), β running one observation
#    step, and a uniqueness law that is the coinduction principle
#    (bisimulation implies equality). Every ν 𝔽 is DERIVABLE (an
#    ℕ-indexed limit — see SUBSUMPTION in the coinductive notes);
#    the scheme is kept for structural identity and one-step β.

///////////// Syntax ///////////////

# signature identifier
x ::= <signature-entry-identifier>

# signature context — TWO entry kinds; type definitions and type
# declarations are the A = 𝕌ℓ instances. There is no constraint kind:
# an assumed equation is a
# HOLE at the equation's prop — a declaration at (a₀ ≡ a₁ ∈ A),
# read back through el-reflect and closed by INSTANTIATION with ⋆
# (see DEFINITIONAL AND OPEN SIGNATURES)
Σ ::= ε
    | Σ (Γ ⊦ x ≔ a : A)     # definition
    | Σ (Γ ⊦ x : A)         # declaration (a HOLE — no definiens)

# typing context
Γ ::= ε      # empty typing context
    | Γ ▷ T  # extended typing context

# A defined (meta-level) notion
# Γ‖ₙ: the (n+1)-th type in Γ counting from the right (0 = the innermost
# extension), i.e. the type ☐ₙ names before weakening.
(Γ ▷ A)‖₀     ≜ A[↑]
(Γ ▷ A)‖ₙ₊₁   ≜ Γ‖ₙ[↑]

# typing context substitution
σ, τ ::=
       ·             # empty substitution
     | σ, t          # extension substitution
     | σ ∘ σ         # composition substitution
     | id            # identity substitution
     | ↑             # weakening substitution

# typing context normal substitution
e˲, t˲, p˲ ::= · | t˲, t

# term — ONE sort: the type and element grammars of earlier
# presentations are merged. A term is a TYPE when it is typed at a
# universe 𝕌ℓ. DISPLAY CONVENTION: the metavariables T, A, B, C range
# over terms standing in type position, t, a, b, e over terms in
# element position — one grammar, two reading aids. The formers 𝟘 𝟙 ℕ
# → × ⊎ / (and the QIIT sorts and ν) are typed at the universe their
# components sit at, and at every higher one by CUMULATIVITY
# (code-lift — El is retired); the level-0 instances are the CODES of
# earlier presentations and keep their code-* names. The Ω-formers ≡
# and ∥·∥ are typed at Ω (as props) and thence at 𝕌₀ and up, by
# PROP-CUMULATIVITY (prop-lift — Prf is retired: a proposition IS its
# type of proofs, and a 𝕌₀ code).
t, T ::= x [e˲]      # signature reference
    | ☐ᵢ             # i-th element in the typing context
    | 𝕌ℓ             # the ℓ-th predicative universe (ℓ a natural-number
                     #   literal): a type at 𝕌ℓ₊₁; 𝕌 alone abbreviates 𝕌₀
    | Ω              # universe of mere propositions: a type at 𝕌₁, and
                     #   deliberately NOT at 𝕌₀ — see THE TOWER
    | 𝟘              # empty type
    | 𝟙              # unit type
    | ℕ              # naturals
    | t → t          # dependent product (Π)
    | t × t          # dependent sum (Σ)
    | t ⊎ t          # non-dependent sum (disjoint union)
    | t / t          # quotient by an Ω-valued relation
    | λ t            # dependent product type introduction
    | t t            # dependent product type elimination
    | let t t        # let-expression (definiens, body — the body
                     #   binds the definiens AND its unfolding
                     #   equation; see the let block)
    | t , t          # dependent sum type introduction
    | t .π₁          # dependent sum type elimination (1)
    | t .π₂          # dependent sum type elimination (2)
    | inj₁ t         # non-dependent sum type introduction (left)
    | inj₂ t         # non-dependent sum type introduction (right)
    | ⊎-elim t t t   # non-dependent sum type elimination
                     #   (left case, right case, eliminee)
    | t ≡ t ∈ T      # equality PROPOSITION — an Ω-element, and by
                     #   prop-lift a type; T an arbitrary type, the
                     #   universes included, so equality props exist
                     #   between types and type equality is a
                     #   proposition (see the Ω block)
    | 𝟘-elim t
    | ()             # the only element of 𝟙
    | Z
    | S t
    | ℕ-elim t t t
    | class t        # quotient type introduction
    | quot-elim t t  # quotient type elimination
    | ∥T∥            # squash: proposition from an arbitrary type, of
                     #   any level — the impredicative step, and with
                     #   Prf retired the ONE mediator from types to
                     #   props; a prop and (by prop-lift) a type
    | ⋆              # the canonical proof of a true proposition
    | 𝒮.𝕤 ē          # sort 𝕤 of a QIIT signature 𝒮 at index spine ē —
                     #   a type at the signature's level; 𝒮 is
                     #   carried in the term, so QIIT equality is
                     #   structural (see "Quotient inductive-inductive
                     #   types")
    | 𝒮.𝕔 θ          # POINT constructor 𝕔 of 𝒮, SATURATED: θ a full
                     #   argument spine, like every other former
                     #   (equation constructors mint no term: their
                     #   content is a judgement — see el-qiit-path)
    | 𝒮.𝕤-elim ℰ ē t # QIIT eliminator (elimination problem ℰ, indices ē,
                     #   eliminee t) — see the QIIT section
    | ν 𝔽            # coinductive type at polynomial 𝔽 — a type at the
                     #   polynomial's level; 𝔽 is carried in the term,
                     #   so ν-equality is structural (see "Coinductive
                     #   types")
    | out t          # coinductive observation (the ELIMINATOR)
    | corec 𝔽 t t t  # corecursor (the INTRODUCTION: polynomial, carrier
                     #   code, coalgebra body, seed — 𝔽 and the carrier are
                     #   CARRIED, like ℰ at 𝒮.𝕤-elim: el-nu-beta consumes
                     #   map_𝔽, so the redex must be self-contained)

# (type) telescope
Δ ::= ε | T ◁ Δ

# (element) spine
ē ::= · | e, ē

///////// Conventions: how to read the rules /////////

# The rules below are presented COMPACTLY. Each convention comes with its
# mechanical expansion, so the fully explicit form of every rule is
# recoverable without judgement calls. (The previous fully-explicit
# presentation additionally carried, with every rule, an argument-labelling
# scheme consumed by the since-removed .rules derivation checker; that
# interface lives on in git history only.)
#
# * AMBIENT SIGNATURE. Every judgement is relative to a signature Σ,
#   presupposed well-formed. The Σ prefix and the premise `Σ sig` are
#   omitted everywhere; rules that inspect or extend Σ (the sig rules,
#   the x[e˲] rules) name it explicitly. Expansion: prefix every
#   judgement with `Σ ⊦`/`Σ Γ ⊦` as appropriate and add `Σ sig` as the
#   first premise of every rule.
#
# * PRESUPPOSITIONS. Each judgement form PRESUPPOSES the well-formedness
#   of its parts, as listed in the judgement-form table below. A rule
#   omits every premise that lies in the presupposition CLOSURE of its
#   retained premises and its conclusion (the closure: start from the
#   retained premises and the conclusion, add their presuppositions, and
#   close transitively). Expansion: add the closure back as explicit
#   premises — this recovers the previous exhaustive style, where e.g.
#   `Γ ▷ A ⊦ f : B` was always accompanied by `Γ ctx`, `Γ ⊦ A : 𝕌ℓ` and
#   `Γ ▷ A ⊦ B : 𝕌ℓ`. Premises NOT in the closure are never omitted: in
#   particular eliminator motives, the middle subject of a transitivity,
#   and the data of the coercion rules are genuine inputs and always
#   appear.
#
# * GROUPED CONCLUSIONS. A rule with several conclusions below the line
#   abbreviates one rule per conclusion (same premises).
#
# * EQUALITY IS THE JUDGEMENT. The one judgement form of the theory
#   is the typed equation Γ ⊦ a₀ ≐ a₁ : A. Membership is its DIAGONAL,
#   by NOTATION —

    Γ ⊦ a : A    ≜    Γ ⊦ a ≐ a : A

#   — so "a is an element of A" means "a is related to itself in A",
#   and el-refl below is not a rule but the notation read backwards.
#   The equality PROPOSITION (a₀ ≡ a₁ ∈ A) is a separate thing, an
#   element of Ω that INTERNALIZES the judgement: el-eq-i takes the
#   judgement to its canonical inhabitant ⋆, el-reflect takes any
#   inhabitant back to the judgement (the Ω block). The remaining
#   equality spellings are META-DEFINITIONS over the judgement, their
#   diagonals the corresponding well-formedness:
#
#     Γ₀ ≐ Γ₁ ctx             pointwise: ε ≐ ε, and
#                             Γ₀ ▷ A₀ ≐ Γ₁ ▷ A₁ iff Γ₀ ≐ Γ₁ ctx and
#                             Γ₁ ⊦ A₀ ≐ A₁ : 𝕌ℓ (ctx-ext-cong is the
#                             defining clause; Γ ctx is Γ ≐ Γ ctx)
#     σ₀ ≐ σ₁ : Γ ⇒ Δ         EXTENSIONAL: Γ ⊦ ☐ᵢ[σ₀] ≐ ☐ᵢ[σ₁] : Δ‖ᵢ[σ₁]
#                             for every i < |Δ| — the substitution
#                             calculus's own equations (assoc, the id
#                             laws, wk-ext, eta, ...) are then
#                             META-LEMMAS, by the var-sub-* clauses;
#                             σ : Γ ⇒ Δ is σ ≐ σ
#     e˲₀ ≐ e˲₁ : Γ ⇒ Δ norm  pointwise (sub-norm-ext-cong defining)
#     Γ ⊦ Δ₀ ≐ Δ₁ tel         pointwise (tel-ext-cong defining)
#     Γ ⊦ ē₀ ≐ ē₁ : Δ         pointwise (sp-ext-cong defining)
#
#   THE EQUIVALENCE structure is two RULES, stated once here (the
#   third, reflexivity, is the notation) —

    Γ ⊦ a : A         Γ ⊦ a₀ ≐ a₁ : A       Γ ⊦ a₀ ≐ a₁ : A   Γ ⊦ a₁ ≐ a₂ : A
    ---------(el-refl) ---------------(el-sym) --------------------------------(el-trans, via a₁)
    Γ ⊦ a ≐ a : A     Γ ⊦ a₁ ≐ a₀ : A       Γ ⊦ a₀ ≐ a₂ : A

#   (transitivity's middle subject a₁, with its typing, is an input;
#   ty-refl/-sym/-trans of earlier presentations are the A = 𝕌ℓ
#   instances). For the meta-defined spellings, refl/sym/trans are
#   META-LEMMAS, pointwise from these (the former ctx-/sub-/sub-norm-/
#   tel-/sp- refl/sym/trans instances). Pointwise equality of
#   constants and atoms (ε ≐ ε ctx, id ≐ id, ↑ ≐ ↑, · ≐ ·,
#   x[e˲] ≐ x[e˲], ...) are refl instances and are not stated.
#
# * THE DOUBLING CONVENTION. A FORMER rule — a formation, introduction
#   or elimination rule, whose conclusion is displayed as a typing
#   Γ ⊦ F(x̄) : T — is DISPLAYED in its diagonal form and STATES its
#   full form, the congruence: every metavariable of the term sort
#   (and of the substitution, telescope and spine sorts) that occurs
#   in the conclusion's subject is split into a LEFT instance x₀ and a
#   RIGHT instance x₁; each premise Γ′ ⊦ x : T′ becomes the equation
#   Γ′ ⊦ x₀ ≐ x₁ : T′; and every OTHER occurrence — in the type slots
#   of premises and conclusion, in the contexts of the premises (the
#   Γ ▷ A of a binder), in the substitutions that instantiate a type
#   — takes the RIGHT instance (B[id, e₁], Γ ▷ A₁ ⊦ B₀ ≐ B₁; the
#   left instance's premise is then well-typed by the domain equation
#   and coercion). Premises that are not typings of a subject part —
#   side conditions, Σ-membership, level bounds, the carried signature
#   𝒮 or polynomial 𝔽 (inert syntax, compared for identity, never
#   doubled), the ToS-zone premises — are unchanged. The diagonal
#   x₀ = x₁ = x recovers the display. Expansion: mechanical, by this
#   clause. Rules whose conclusion is ALREADY an equation — the
#   computation rules (≜), the uniqueness rules (η), the irrelevance,
#   extensionality, lift/restrict, coercion and reflection rules —
#   are stated exactly as displayed and are NOT doubled; their typing
#   premises are diagonals. So the congruence of every former is its
#   own rule read in full, and the master congruence of substitution,
#   el-sub-cong, is the full form of el-sub. Where a source cites a
#   congruence by its historical name (ty-pi-cong, code-eq-cong, …)
#   the full form is displayed under that name beside the rule it
#   doubles; the name denotes the same rule.
#
# * DEFINITIONAL EQUALITY. A rule concluding J ≜ K asserts the
#   equation J ≐ K and additionally marks it as a computation step,
#   oriented left to right. Its presuppositions are those of the
#   equation.

# * NAMES. Every rule carries a canonical name on its inference line,
#   following one homogeneous scheme — <class>-<former>-<kind> — where
#   the class prefix names the judgement class (ctx, sub, sub-norm,
#   el, tel, sp, poly), EXCEPT that within the element class the
#   prefix records the conclusion's universe: ty- for conclusions at
#   a universe 𝕌ℓ (types), code- for the LEVEL-0 instances displayed
#   under their historical names (codes), el- otherwise. (The ty
#   judgement class is dissolved into el at the universes; the
#   prefixes survive as naming conventions precisely so that rule
#   names are stable across the dissolution and the tower — see
#   DISSOLVED NAMES at the end.)
#   The former names the connective or constructor, and the kind
#   distinguishes introduction (i), elimination (e), computation
#   (beta), uniqueness (eta), congruence (cong), injectivity (inj),
#   substitution action (sub), and coercion (coe). A -cong name
#   denotes the FULL (doubled) form of the former rule it is named
#   after (THE DOUBLING CONVENTION), displayed separately only where
#   a source cites it. These names are the ones docs/NovaKernel.txt
#   and docs/NovaElaboration.txt cite; there are no other synonyms.

///////// Judgement forms and their presuppositions /////////

  Form                         Presupposes
  --------------------------   ------------------------------------
  Σ sig                        —
  Γ₀ ≐ Γ₁ ctx                  —              (Γ ctx is Γ ≐ Γ ctx)
  σ₀ ≐ σ₁ : Γ ⇒ Δ              Γ ctx;  Δ ctx  (σ : Γ ⇒ Δ is σ ≐ σ)
  e˲₀ ≐ e˲₁ : Γ ⇒ Δ norm       Γ ctx;  Δ ctx
  Γ ⊦ a₀ ≐ a₁ : A              Γ ⊦ A : 𝕌ℓ    (for some ℓ; Γ ⊦ a : A is a ≐ a)
  # ONE judgement, the equation, with ONE presupposition: the type
  # slot holds a term typed at some universe — a universe itself
  # included, since 𝕌ℓ : 𝕌ℓ₊₁ (THE TOWER); "typed at" is itself the
  # diagonal Γ ⊦ A ≐ A : 𝕌ℓ. The level is not part of the form: by
  # cumulativity a type at 𝕌ℓ is at every 𝕌ℓ′ above, and a proposition
  # (typed at Ω) is at 𝕌₀ by prop-lift. The context, substitution,
  # telescope and spine equations are the pointwise meta-definitions
  # of EQUALITY in the conventions, their diagonals the corresponding
  # well-formedness.
  Γ ⊦ Δ₀ ≐ Δ₁ tel              Γ ctx          (Γ ⊦ Δ tel is Δ ≐ Δ)
  Γ ⊦ ē₀ ≐ ē₁ : Δ              Γ ⊦ Δ tel      (Γ ⊦ ē : Δ is ē ≐ ē)
  Γ ⊦ Φ qctx                   Γ ctx        (qiit-context)
  Γ ; Φ ⊦ 𝔄 qty                Γ ⊦ Φ qctx   (qiit-type)
  Γ ; Φ ⊦ 𝕥 : 𝔄                Γ ; Φ ⊦ 𝔄 qty (qiit-term)
  Γ ⊦ ς : Φ₀ ⇒ Φ₁              Γ ⊦ Φ₀ qctx;  Γ ⊦ Φ₁ qctx   (qiit-substitution)
  Γ ⊦ 𝒮 qsig                   Γ ctx        (QIIT signature; ≜ Γ ⊦ 𝒮 qctx)
  Γ ⊦ C̄ : 𝒮 mot                Γ ⊦ 𝒮 qsig   (motive family)
  Γ ⊦ ℰ : 𝒮 dalg               Γ ⊦ 𝒮 qsig   (displayed algebra, ℰ = C̄ ; m̄)
  Γ ⊦ ℰ : 𝒮 eprob              Γ ⊦ ℰ : 𝒮 dalg   (elimination problem)
  Γ ⊦ φ : C̄ sect               Γ ⊦ C̄ : 𝒮 mot    (section candidate)
  Γ ⊦ 𝔽 poly                   Γ ctx        (polynomial — see "Coinductive types")
  𝒮 ≼ ℓ,  𝔽 ≼ ℓ                META-DEFINED level bounds: every Nova type the
                               signature / polynomial embeds is typed at 𝕌ℓ at
                               its position (ty-qiit, ty-nu)
  # the theory-of-signatures judgements (dual zone Γ ; Φ — Nova zone,
  # then ToS zone) are defined in the QIIT section; a signature is
  # nothing but a well-formed qiit-context. Like signatures,

# DEFINITIONAL AND OPEN SIGNATURES. A signature is DEFINITIONAL when
# every entry is a definition (sig-def). A DECLARATION makes it OPEN:
# a hole — a name with a type and no definiens, whose references
# x[e˲] are STUCK (el-sig-decl below; deliberately no -beta). Type
# holes are the A = 𝕌ℓ instances. An assumed EQUATION is a hole at the
# equation's prop — an entry (Γ ⊦ h : (a₀ ≡ a₁ ∈ A)), A = 𝕌ℓ for a
# type equation — whose reference h[e˲] yields the instantiated
# equation by el-reflect: what the retired constraint kind provided
# through its own rules (sig-eq/el-sig-eq) is one el-reflect away
# from an ordinary declaration, so the kind is gone. Open signatures
# are the working states of an elaboration run
# (docs/NovaElaboration.txt): the declarations of the run's signature
# ARE its open proof obligations, and a run is ACCEPTED only once its
# signature is definitional.
#
# The canonical-forms semantics below reads over definitional
# signatures only. An open signature denotes the CLASS of its
# definitional REFINEMENTS — the signatures obtained by instantiating
# every declaration (the one admissible principle next); every
# judgement derived over the open signature holds over each
# refinement. The class may be EMPTY (a hole at ∥𝟘∥, or at
# (Z ≡ S Z ∈ ℕ)): judgements under unsatisfiable assumptions
# carry no absolute content — which is why acceptance demands a
# definitional signature and nothing weaker.
#
# The refinement principle is a META-THEOREM (by induction on
# derivations), not a rule of the theory — the workflow it justifies
# is edit-and-rerun, never an in-place signature surgery:
#
# * INSTANTIATION (signature cut). If Σ (Γ ⊦ x : A) Σ' ⊦ J and
#   Σ Γ ⊦ t : A — the filling term lives in the PREFIX preceding the
#   hole — then Σ Σ'[t/x] ⊦ J[t/x], where [t/x] replaces every
#   reference x[e˲] by t[e˲]. The A = 𝕌ℓ instance covers type
#   declarations, filled by Σ Γ ⊦ T : 𝕌ℓ. The IN-PLACE variant needs
#   no substitution at all:
#   Σ (Γ ⊦ x ≔ t : A) Σ' ⊦ J follows directly, since every rule that
#   applied to the declaration entry has its conclusion re-derivable
#   from the definition entry (el-sig-decl's conclusion is
#   el-sig-var's) and no rule depends on x LACKING a body — the flip
#   only refines, adding the equations x[e˲] ≜ t[e˲].
#   DISCHARGING an equation obligation is the prop instance: the hole
#   h : (a₀ ≡ a₁ ∈ A) fills with ⋆ exactly when the equation is
#   derivable in its prefix (el-eq-i), the same condition the retired
#   DISCHARGE meta-theorem demanded of a constraint — one open-entry
#   kind, one closing move.
#
# Substitution action is uniform in the entry kind: el-sub-sig-var,
# stated below for definitions, is adopted verbatim for declarations —
# x[e˲][σ] ≜ x[e˲ ∘ σ] whichever entry x names.

#
# THE TOWER. The types are the terms typed at a universe; the rules
# of this section are the old type-formation and type-equality rules,
# re-read as element rules whose conclusions sit at 𝕌ℓ. The design in
# full:
#
#  * A CUMULATIVE TOWER 𝕌₀ : 𝕌₁ : 𝕌₂ : … — each universe a type one
#    level up (ty-univ), never at its own level (no Γ ⊦ 𝕌ℓ : 𝕌ℓ:
#    Girard), and each a SUBUNIVERSE of the next (code-lift: a type of
#    level ℓ is a type of level ℓ+1, its equality lifting and
#    restricting). There is no top and no universe of all types;
#    "large" means "one level up". Levels are LITERALS: the theory has
#    no level variables and no level polymorphism, and a statement
#    quantifying over 𝕌₀ is a 𝕌₁ type.
#  * Ω BELOW THE BOTTOM: Ω : 𝕌₁ (ty-prop), and every proposition is a
#    𝕌₀ code (prop-lift). Ω itself is deliberately NOT a 𝕌₀ code —
#    the one asymmetry of the tower, and a semantic fact, not a
#    convention: in a realizability reading a proposition is a
#    subsingleton and hence data, while the type of all propositions
#    is not (a program cannot tell two propositions apart), so Ω : 𝕌₀
#    is refuted there and A → Ω stays one level above A. In the
#    setoid reading Ω is the two-point set and nothing would break;
#    the theory keeps the reading both models share.
#  * Every EXCLUSION is by absence of a derivation, not by grammar: a
#    universe at its own level, Ω at 𝕌₀, a Π over all types — each
#    would need a typing no rule gives.
#  * The FORMERS are stated ONCE, at a level ℓ common to their
#    components (a component at a lower level arrives by code-lift):
#    the level of 𝟘, 𝟙, ℕ is 0; of a Π, Σ, ⊎, / the level of its
#    components (the relation slot of / is Ω and contributes nothing);
#    of a QIIT sort and a ν-type the level of the signature or
#    polynomial. Their LEVEL-0 instances are the universe CODES of
#    earlier presentations and are displayed below under their code-*
#    names, for the citations; they are the same rules.
#  * The GENERAL rules of the old type judgement are instances of
#    the element rules at A = 𝕌ℓ and are not restated: ty-sub,
#    ty-sub-id, ty-sub-comp are el-sub, el-sub-id, el-sub-comp;
#    ty-coe-ctx and ty-eq-coe-ctx are el-coe-ctx and el-eq-coe-ctx;
#    ty-sub-cong(-fix) is el-sub-cong(-fix); ty-sig-var, ty-sig-beta,
#    ty-sig-decl and ty-sub-sig-var are el-sig-var, el-sig-beta,
#    el-sig-decl and el-sub-sig-var at an entry whose A is a universe.
#  * ty-zero-elim (type equality from absurdity) is DERIVABLE and
#    retired: from Γ ⊦ t : 𝟘, el-zero-e at the type
#    (A ≡ B ∈ 𝕌ℓ) — code-eq admits the universes, see the Ω block —
#    gives 𝟘-elim t : (A ≡ B ∈ 𝕌ℓ), and el-reflect concludes
#    Γ ⊦ A ≐ B : 𝕌ℓ. (The same derivation gives a ≐ b : C at ANY type
#    under absurdity — absurdity collapses every equation, type
#    equations included.)
#  * NAMING. Rules concluding at a universe keep their ty- prefix
#    (see NAMES in the conventions): the prefix now reads "typing at
#    𝕌ℓ", code- "the level-0 display".

# level ℓ+1, by the lift below, and its equality lifts and restricts.
# The three rules are the invisible remnant of the retired decoding
# former — code-lift is ty-el, code-lift-eq is ty-el-cong,
# code-restrict is ty-el-inj — and with nothing left to decode, the
# ty-el-* computation rules are VACUOUS (each equation's two sides
# are now one term). code-restrict is MANDATORY, not optional: it is
# what keeps the equality props (a ≡ b ∈ 𝕌ℓ) and (a ≡ b ∈ 𝕌ℓ₊₁)

# level ℓ are a sub-collection of those of level ℓ+1 (NovaModel's
# `el` embedding, now an inclusion); the lift is that inclusion, and
# type equality restricted to the lower image is the lower level's
# own — exactly code-restrict. Cumulativity acts at the ROOT of a
# type only: a function into 𝕌ℓ is not thereby a function into 𝕌ℓ₊₁
# (η-expand it); a context entry at 𝕌ℓ is not one at 𝕌ℓ₊₁.

# proofs, by the lift below, and its equality lifts and restricts —
# INTO 𝕌₀, the bottom of the tower, whence everywhere by code-lift.
# prop-lift is ty-prf with the wrapper deleted; prop-restrict is
# MANDATORY for the same reason code-restrict is (it keeps the props
# (p ≡ q ∈ Ω) and (p ≡ q ∈ 𝕌₀) equi-true at props, so the ∈-slot
# stays well-defined). THE ASYMMETRY with the 𝕌 triple, stated
# plainly: code-lift-eq imports nothing (a level's equality is the
# restriction of the next level's structural equality on the nose),
# but prop-lift-eq imports PROPOSITIONAL EXTENSIONALITY into 𝕌₀ — on
# the prop cluster, type equality is mere equivalence (code-prop-eq).
# Type equality at EVERY universe is thereafter MIXED: structural on
# the code cluster, extensional on the prop cluster. This is not a
# new cost of the tower: with the quotient slot Ω-valued, the
# 𝕌₀-code prf r ≜ Id (ℕ / r̂) (class Z) (class (S Z)) already carried
# every proposition into 𝕌₀ up to iff (see the impredicativity note
# in the Ω block), and prf r ≐ prf r′ : 𝕌₀ whenever r ⟺ r′ — the
# small universe's equality was mixed before the lift made it so
# directly. prop-lift-eq is PRIMITIVE, not an el-sub-cong instance
# (the master congruence at ☐₀ over Γ ▷ Ω concludes at Ω, not 𝕌₀ —
# nothing else lifts the coarse equality). CROSS-CLUSTER equations
# are underivable by absence: ∥𝟙∥ ≐ 𝟙 : 𝕌₀ has no derivation —
# prop-restrict needs both sides at Ω (𝟙 is not: Ω's only formers
# are ≡ and ∥·∥), and no structural rule reaches a prop-headed side
# — and the model refutes them (disjoint summands, see SEMANTICS
# below). Both are contractible; the theory keeps them intensionally
# distinct, exactly as A / R vs A / R⁺. SEMANTICS: each universe's
# codes gain a PROP summand, disjoint from the structural codes,
# whose constructor argument is QUOTIENTED by iff — the PER of 𝕌ℓ is
# constructor-structural on one summand and extensional on the
# other; no-confusion BETWEEN the summands is the meta-property that
# refutes cross-cluster equalities. This is the boundary the retired
# Prf used to spell as a single non-injective former; retiring it
# moves the carve-out into the universes' own equality. Ω ITSELF has
# no 𝕌₀ code (THE TOWER): the lift is of propositions, never of
# their universe.

///////// Type constructor injectivity /////////
#
# The congruence rules above run downward: equal components give equal
# composites. The rules below run upward: equal composites give equal
# components. They are NOT derivable from the rest of the theory — in
# the plain set-theoretic model (types as sets, function types as sets
# of graphs) the hypothesis h : ((𝟙 → 𝟘) ≡ (ℕ → 𝟘) ∈ 𝕌₀) is satisfiable
# (both function spaces are the empty set), yet 𝟙 ≐ ℕ is refuted, so
# before these rules the composite equality was derivable in a context
# where the component equality was not. Adding them is a semantic
# commitment, and it is the one this file's preface already makes: a
# type denotes a structural CODE (docs/NovaModel.txt's code
# universes), so two Π-types are equal exactly when their heads and
# components are — the rules are the meta's ordinary constructor
# injectivity, read back through the interpretation — and likewise
# for the other formers. (The PROP summand is the deliberate
# exception: its equality is extensional, and it has no injectivity —
# see PROP-CUMULATIVITY and the prop-cluster note below.)
# Under that semantics these rules are sound;
# models that collapse structurally distinct types (the set-theoretic
# one above) are hereby excluded, and the code-universe model shows
# the exclusion is not vacuous: all the rules hold in it at once
# (NovaModel's soundness notes). A concrete consequence:
# a context hypothesizing (𝟙 → 𝟘) ≡ (ℕ → 𝟘) ∈ 𝕌₀ is now INCONSISTENT
# (𝟙 ≐ ℕ gives Z ≐ S Z : ℕ via el-one-prop and coercion, and a ℕ-elim
# discriminator into 𝕌₀ turns that into an inhabitant of 𝟘).
#
# Notes:
#  * The codomain/relation components are concluded UNDER the domain —
#    this is what keeps the rules compatible with empty-domain
#    collapses (𝟘 → 𝟙 ≐ 𝟘 → ℕ is harmless: under a 𝟘-hypothesis the
#    component 𝟙 ≐ ℕ is derivable by absurdity anyway).
#  * Quotient relations are Ω-valued, so the relation components are
#    compared at Ω, where judgemental equality IS logical equivalence
#    (code-prop-eq). Quotient type equality therefore coincides with
#    NuPRL's iff-based one — obtained through structural rules rather
#    than a bespoke clause. This does not compromise a universe's
#    structural discipline: it is structural in its FORMERS and
#    extensional in its element slots (≐ on elements is extensional
#    via reflection); the Ω-slot in ty-quot is the same pattern, and
#    the prop summand (PROP-CUMULATIVITY) the same pattern once more.
#  * class stays NON-injective: class a ≐ class b : A / R does not
#    entail a ≐ b — that is the entire point of quotients.
#  * The PROP cluster (∥-∥ and ≡, lifted by prop-lift) has NO
#    injectivity rules: Ω is the anti-structural universe, compared
#    by inhabitation alone (see the Ω block in the element rules) —
#    with Prf retired this is a property of each universe's own
#    equality on the prop summand, not of a wrapper. Equality is
#    Ω-VALUED, so it
#    inherits this: there is no eq-injectivity — code-prop-eq makes
#    (Z ≡ Z ∈ ℕ) ≐ (S Z ≡ S Z ∈ ℕ) : Ω (both true), while the
#    endpoint equalities Z ≐ S Z are refutable.
#  * No-confusion (a Π-type is never equal to ℕ, a Σ-type, ...) is NOT
#    expressible as a rule of this positive inference system, and in
#    inconsistent contexts it is false. It remains a meta-property of
#    consistent contexts, inherited from the meta's no-confusion for
#    the code universes (docs/NovaModel.txt).
#  * S-injectivity and pair-injectivity need no rules: they are already
#    derivable (congruence with a ℕ-elim predecessor, respectively the
#    projections). Ditto inj₁/inj₂-injectivity and -disjointness:
#    injectivity by a ⊎-elim retraction at constant motive A whose
#    right case returns a fixed default (the compared element itself
#    serves), disjointness by a ⊎-elim discriminator at constant
#    motive ℕ (Z left, S Z right) followed by the standard Z ≐ S Z
#    refutation. The TYPE former ⊎ is injective by rule below, like
#    every other structural former.

# ≐ is an equivalence, so class equality is R's equivalence closure and
# nothing less. What IS recovered from class a ≐ class b — R⁺, exactly,
# and R itself when R is an equivalence — is EFFECTIVITY, derived in the
# Ω block below (Consequences for quotients, item 2); it needs Ω as a
# quot-elim motive, which is why B ranges over TYPES here and Ω is one
# (ty-prop).

# Ω: equality, squash, proof irrelevance, propositional
# extensionality.
#
# Ω is the universe of mere propositions, below the tower's bottom
# (Ω : 𝕌₁, THE TOWER); its equality discipline is the mirror image
# of the structural universes'. Structural codes are compared
# STRUCTURALLY (the injectivity block); Ω's codes are compared by
# INHABITATION alone (code-prop-eq). Each discipline is sound only on
# its own cluster, and the two COEXIST at every 𝕌ℓ on disjoint
# clusters (PROP-CUMULATIVITY: a proposition is a 𝕌₀ code; Ω itself
# is a 𝕌₁ code and never a 𝕌₀ code; no rule crosses the clusters,
# and there is no Ω analogue of any inj rule).
#
# PROPOSITIONAL EQUALITY LIVES HERE: (a₀ ≡ a₁ ∈ A) is an ELEMENT of
# Ω, not a type (the OTT design — observational equality in a
# definitionally irrelevant Prop). What this buys, and what it
# forfeits:
#  * Proof irrelevance is inherited from el-prf-prop — no separate
#    el-eq-eta is needed, and equality hypotheses never carry data.
#  * The canonical proof is ⋆ — Refl is RETIRED. This is forced, not
#    stylistic: code-prop-eq + prop-lift-eq + el-ty-coe move proofs
#    between iff-equal props UNCHANGED (a true equation is ≐-equal to
#    ∥𝟙∥ at Ω), so every inhabited prop must have literally the same
#    canonical form.
#  * A is an ARBITRARY type, the universes included: equality props
#    exist between types, (A ≡ B ∈ 𝕌ℓ) : Ω — TYPE EQUALITY IS A
#    PROPOSITION, at every level, since every type is an element of
#    some 𝕌ℓ. code-eq needs no special case for this: its endpoint
#    premises are typing judgements. With el-eq-i and el-reflect at
#    A = 𝕌ℓ, type equality is reflection-complete exactly like
#    element equality — a type-equality hypothesis is an ordinary
#    context entry h : (A ≡ B ∈ 𝕌ℓ), and ty-zero-elim of earlier
#    presentations is derivable (see THE TOWER).
#  * Ω-positions take equations directly — quotient relations need no
#    squash (ℕ × ℕ / (p q. p .π₁ + q .π₂ ≡ p .π₂ + q .π₁ ∈ ℕ)), and
#    the squashed-equality connective below is subsumed.
#  * NO injectivity, inherited from Ω's discipline; but a 𝕌₀-code,
#    by prop-lift, so equational content IS storable in a small type
#    directly — a Σ over a proposition, a positivity witness with its
#    modulus — with the extensional equality of the prop cluster
#    riding along (the prf-code quotient trick below, which used to
#    manufacture such a code, is now the lift itself).
#
# Notes:
#  * Realizer irrelevance is FORCED, not chosen: code-prop-eq +
#    prop-lift-eq + el-ty-coe move an element between iff-equal props
#    UNCHANGED, which is sound only if those props (as types) have
#    literally the same canonical forms. So a prop never exposes the
#    squashed proofs: its one canonical form is ⋆ (cf. NuPRL's Ax),
#    and el-prf-prop equates all members. Consequently ∥A∥, as a
#    type, does NOT reduce to A, and there is no code-squash-inj:
#    ∥𝟙∥ ≐ (Z ≡ Z ∈ ℕ) : Ω holds by code-prop-eq while the squashees
#    are structurally distinct. Ω adds no computation rules beyond
#    substitution actions (squash's idempotence is ADMISSIBLE, not a
#    ≜ — see code-squash-idem); the preface's normalization story is
#    unchanged.
#  * Squash is the only way in: ∥-∥ takes an arbitrary TYPE, not a
#    𝕌-code, so the connectives are signature definitions, not rules —
#      ⊤ ≔ ∥𝟙∥,  ⊥ ≔ ∥𝟘∥,  p ∧ q ≔ ∥p × q[↑]∥,
#      p ⊃ q ≔ ∥p → q[↑]∥,  ∀ over A ≔ ∥A → p∥,
#      ∃ over A ≔ ∥A × p∥
#    (props stand directly in the domains and components — prop-lift)
#    — equality (≡) is the one PRIMITIVE prop beside ∥-∥ (squashing
#    it again is redundant by code-squash-idem). Every other definable
#    prop is ∥-∥-headed, so the eliminators below lose no generality;
#    derived intro/elim principles come from el-squash-i /
#    el-squash-e-* over the underlying former.
#  * Elimination goes only into equations and props: a squashed
#    hypothesis may be unsquashed exactly when the goal cannot
#    observe WHICH proof was used — equational goals (judgements do
#    not consult witnesses) and propositional goals (the witness is
#    ⋆ either way). With ≡ Ω-valued, el-squash-e-eq is ADMISSIBLE:
#    equality props exist at every type (large included), so el-eq-i
#    under the binder, el-squash-e-prf and el-reflect derive it. It
#    is kept as a rule for the kernel's convenience. There is
#    deliberately NO eliminator into arbitrary types — el-prf-prop
#    would force it constant, and it would refute witness
#    irrelevance in the model. The eliminators need no congruence
#    rules: their conclusions are equations, respectively ⋆-typings
#    covered by el-prf-prop.
#  * IMPREDICATIVITY. ∥-∥ squashes arbitrary types of every level,
#    including quantifications over Ω itself and over any 𝕌ℓ. This is sound
#    because the candidate denotations of props form a FIXED
#    two-point lattice — the empty and the unit subsingleton setoid —
#    that does not grow with the quantification domain: a universally
#    quantified prop is an infimum in that lattice, witnessed
#    uniformly by ⋆ (precedent: the proof-irrelevant setoid models,
#    where Prop is exactly this lattice; the PER models of CC ran the
#    same argument with realizers). The
#    restrictions above are the license for this; each blocks a known
#    paradox:
#      - proof irrelevance blocks Girard/Hurkens: nothing can be
#        stored in a prop and retrieved for diagonalization (in
#        particular, Church encodings through Ω are sterile — no
#        data can be smuggled past the size restrictions);
#      - no elimination into arbitrary types blocks unique choice /
#        description, and with it the quotient+choice collapses
#        (Chicli–Pottier–Simpson);
#      - no 𝕌₀-code for Ω ITSELF blocks Reynolds/Cantor: A → Ω is
#        one level above A, so no type contains its own powerset.
#        Individual propositions ARE 𝕌₀ codes (prop-lift), and that
#        is harmless — it was already so up to iff before the lift:
#        with Id the QIIT identity family over a small carrier
#        (Id : (x y : a) ⇛ U ; refl : (x : a) ⇛ El (Id x x)), take
#        prf r ≜ Id (ℕ / r̂) (class Z) (class (S Z)), a 𝕌₀-code whose
#        decoding is inhabited iff r — el-quot-eq plus el-qiit-intro
#        one way, effectivity along (x ≡ y ∈ ℕ) ∨ r plus qiit
#        elimination the other. So the load-bearing prohibition was
#        never on propositions, only on their universe: propositions
#        and powersets embed into the codes of some 𝕌ℓ, never into
#        the elements of a small type — quotient elements cannot
#        store a proposition (coherence forces eliminators out of
#        𝟙/r̂-style types constant), and a universe is never at its
#        own level. Equality props have 𝕌₀ codes like every
#        proposition; what they store is ⋆.
#    Payoff: least relations by intersection — e.g. an equivalence
#    closure r⁺ of an arbitrary relation r, defined by quantifying
#    over all Ω-valued relations containing r — with no inductive
#    machinery. And since ty-quot takes its relation at Ω rather
#    than at a universe, A / r⁺ is at the level of A: quotients by
#    generated congruences stay small.
#  * Consequences for quotients (whose relation slot is Ω-valued —
#    see ty-quot):
#      1. Mutually implied relations give EQUAL quotient types:
#         code-prop-eq under Γ ▷ A ▷ A[↑] gives R₀ ≐ R₁ : Ω, then
#         ty-quot-cong; dually ty-quot-inj returns only iff-content.
#         A proof-relevant presentation is recovered as A / ∥R∥.
#      2. Effectivity, in the ONLY form it can take: quotient equality
#         is the equivalence CLOSURE. For R : Ω over Γ ▷ A ▷ A[↑] with
#         no assumption whatever,
#
#           class a ≐ class b : A / R  ⟺  R⁺[id, a, b] inhabited
#
#         (⟸) R⁺ is least among the equivalences containing R, and
#         (class ☐₁ ≡ class ☐₀ ∈ A / R) is one — el-quot-eq for
#         containment, the EQUIVALENCE RULES for the rest.
#         (⟹) quot-elim at the constant motive Ω with f ≔ R⁺[id, a, ☐₀]:
#         coherence is R⁺ a x ⟺ R⁺ a y under R[id, x, y], by
#         code-prop-eq from R⁺'s OWN transitivity and symmetry (this is
#         why the motive is the closure and not R: nothing about R is
#         needed); then el-quot-beta at class a, congruence along the
#         class equation, prop-lift-eq and el-ty-coe carry R⁺'s
#         reflexivity proof to b. Both directions stay inside A / R — no
#         transport to A / R⁺, which by item 1 is a DIFFERENT type.
#         Corollary: where R is an equivalence, R⁺ collapses into it by
#         leastness and effectivity holds ON THE NOSE — the familiar
#         form, with the hypotheses that make it true.
#         The naive form — R itself back, pointwise, for arbitrary R —
#         is REFUTABLE, not merely unproved: ≐ is an equivalence at
#         every judgement class while ty-quot's relation slot is
#         arbitrary, so at R ≔ (S ☐₁ ≡ ☐₀ ∈ ℕ) one has
#         class Z ≐ class (S (S Z)) by transitivity, whence a proof
#         of (S Z ≡ S (S Z) ∈ ℕ), whence Z ≐ S Z by el-reflect and
#         S-injectivity, whence 𝟘. Nothing may read R off a class
#         equation; only R⁺.
#      3. Equality proofs reflect directly: el-reflect reads
#         a₀ ≐ a₁ : B off any s : (a₀ ≡ a₁ ∈ B) — no squash
#         apparatus is involved.
#  * SEMANTICS. In the setoid model a prop, read as a type through
#    prop-lift, denotes a subsingleton setoid: carrier 𝟙 if p is
#    true, 𝟘 otherwise (all elements related either way) — where ∥A∥ is true iff ⟦A⟧'s carrier is
#    inhabited, and (a₀ ≡ a₁ ∈ A) is true iff ⟦a₀⟧ ~ ⟦a₁⟧ in ⟦A⟧'s
#    relation; ∥A∥ ~ ∥B∥ : Ω iff A and B are equi-inhabited.
#    THE ∈-𝕌ℓ INSTANCE: (A ≡ B ∈ 𝕌ℓ) is true iff ⟦A⟧ and ⟦B⟧ are
#    EQUAL CODES — the model's type equality at level ℓ (with Prf
#    retired this PER is MIXED: structural on the code summand, iff
#    on the prop summand — see PROP-CUMULATIVITY), which is exactly
#    what el-reflect at 𝕌ℓ reads back. This is the one point where
#    the dissolution EXTENDS the theory, and it is sound by the same
#    two-layer construction: prop-truth is defined against the full
#    type system anyway, and code equality of every level is
#    available at that stage; the new prop's type of proofs is the
#    same subsingleton as every other, so nothing is storable through
#    it (no Hurkens vector), and Ω itself has no 𝕌₀ code — the
#    firewall clauses of the impredicativity note are untouched.
#    code-prop-eq holds on the nose (iff-equal props have IDENTICAL
#    denotations); el-squash-e-* are validated by instantiating their
#    premise at any carrier element — the conclusion never consults
#    which one. Model note: the prop layer cannot be built by the
#    same stagewise induction as the rest of the type system (the
#    Π-over-Ω clause consults Ω's full domain, non-monotonically); it
#    is instead given IN ADVANCE — the fixed lattice above, with
#    prop-truth defined against the full type system. A two-layer
#    construction, as in the impredicative-Prop setoid models (and,
#    before them, the PER models of CC). The Ω-valued quotient slot
#    adds no further impredicative dependency: the quotient clause
#    consumes Ω-truth POINTWISE (⟦A / R⟧ keeps ⟦A⟧'s carrier
#    and coarsens its relation by the truth of R at each pair — in
#    the setoid model a quotient is FREE), so quotient codes stay
#    small however impredicative their relation — propositional
#    resizing, in HoTT terms, which the setoid model validates.
#    PRECISELY: the coarsened relation must still be an EQUIVALENCE
#    (that is what a setoid is), so it is the equivalence closure of
#    ⟦A⟧'s relation together with R's truth — exactly R⁺'s
#    denotation. "Coarsens by the truth of R at each pair" is the
#    closure's description only when R is already an equivalence
#    containing ≐_A; in general read the closure, and effectivity
#    (item 2 above) is the syntactic counterpart. This does NOT
#    collapse A / R into A / R⁺: type equality is equality of CODES,
#    the quotient code carries its relation, and R, R⁺ are not
#    pointwise equi-inhabited — so ty-quot-inj is untouched, at the
#    price that two quotient types may denote the same setoid while
#    remaining distinct types.

///////// Quotient inductive-inductive types (signatures) /////////
#
# The formers ℕ and quotient each add ONE type. QIITs add a SCHEME: for
# each well-formed SIGNATURE 𝒮 — a family of mutually-defined, possibly
# index-dependent sorts, generated freely by point constructors and
# quotiented by equation constructors — the rules below license the
# sorts of 𝒮 as types (𝒮.𝕤 ē), their constructors (𝒮.𝕔 θ), the imposed
# path equations, and a dependent eliminator (𝒮.𝕤-elim) with its
# computation and uniqueness laws. Every rule is stated AGAINST a
# signature (⊦ 𝒮 qsig as a premise); a signature is NOT a Σ-entry and
# mints no names — 𝒮 is carried by the formers themselves (as A / R
# carries A and R). These are the inductive-inductive quotient types of
# Altenkirch–Kaposi. The scheme SUBSUMES ℕ, (⊎) and (/), and covers
# indexed
# inductive types (well-founded trees included) and quotient inductive
# types generally; ℕ, (⊎) and (/) are retained for now.
#
# THE EXTENSIONAL PAYOFF. Under equality reflection (with Ω for
# proof-irrelevance) every type is a set: no higher paths, no coherence
# tower, no transport. A path constructor is therefore an equation
# IMPOSED judgementally (via el-reflect), and the eliminator's path
# premises collapse to WELL-DEFINEDNESS conditions — precisely
# quot-elim's f⁼ premise, one per equation, with no apd/transport.
# This degeneration is what lets the scheme be POSTULATED precisely
# rather than through a tower of coherences (contrast the intensional
# HIIT signatures, which need the full apparatus).

# THEORY OF SIGNATURES — grammar. The ToS is a SMALL DEPENDENT TYPE
# THEORY of its own: qiit-contexts are built out of qiit-types,
# qiit-terms are typed at qiit-types, and all argument passing is by
# the ToS's own Π/λ/application — there is no spine syntax. A
# SIGNATURE is nothing but a closed qiit-context: sorts, point
# constructors and equation constructors are ordinary entries,
# distinguished by the HEAD of their type alone.

#   qiit-context
    Φ, 𝒮 ::= ⬦ | Φ ▷ 𝔄          # entries are ANONYMOUS

#   qiit-type
    𝔄 ::= U                     # the universe of codes
        | El 𝕥                  # decoding of a code 𝕥 : U
        | A ⇛ 𝔄                 # EXTERNAL Π — domain a Nova
                                #   type; binds a NOVA variable
        | El 𝕥 ⇛ 𝔄              # INDUCTIVE Π — binds a ToS
                                #   variable

#   qiit-term
    𝕥 ::= ⬡ᵢ                    # ToS VARIABLE, de Bruijn
        | 𝕥 t                   # application to a Nova term
        | 𝕥 𝕥'                  # application to a ToS term
        | λ 𝕥                   # external abstraction (binds
                                #   a NOVA variable)
        | 𝕥₀ ≡ 𝕥₁               # equation CODE (in U, at the
                                #   sides' common El)

#   qiit-sub
    ς ::= 𝕚𝕕 | ⇑                # the ToS's OWN substitution
             | ς ∘ ς            #   calculus, mirroring Nova's
             | ς, 𝕥             #   (ς⁺ ≜ (ς ∘ ⇑, ⬡₀) derived)

#   (A ranges over Nova types, t over Nova terms; ⇛ is the ToS's Π,
#   NOT Nova's →. The variable discipline is NAMELESS, like Nova's own:
#   ⬡ᵢ counts inductive binders and context entries ONLY — ToS
#   variables are ORTHOGONAL to Nova's ☐ᵢ, which external binders bind
#   in the Nova zone, and the two calculi never touch each other's
#   variables. In examples, named binders (x : A) ⇛ …, (𝕧 : El 𝕥) ⇛ …
#   and named entries are DISPLAY SUGAR for the indexed core. Entry
#   references from outside are POSITIONAL: 𝒮(k) = 𝔄 says entry k of 𝒮
#   (in declaration order) is 𝔄, the formers are 𝒮.k, and 𝕤, 𝕔 are used
#   as metavariables for sort / constructor POSITIONS. There is no
#   inductive λ: terms of inductive-Π type arise only as partial
#   applications, which is all signatures need. The ToS has NO
#   computation of its own — substitution application is a
#   META-operation, and signatures are inert syntax, compared per
#   IDENTITY below.)
#
# Strict positivity and externality are GRAMMATICAL, by two features
# working together. First, Π domains are only Nova types or El-codes —
# U and Π-types never occur left of a ⇛. Second, the two Π's bind into
# DIFFERENT ZONES of the dual-zone judgements below: an external
# binder grows the NOVA zone Γ, an inductive binder the ToS zone Φ;
# Nova types are typed over Γ alone, so they cannot mention an
# inductive variable — sort-free automatically, with no projection and
# no side condition.
#
# Entry classification, by the head of the entry's type (every
# qiit-type ends in U or El, so the classification is exhaustive —
# there are no other entry forms to exclude):
#     … ⇛ U               a SORT (its Πs are the index arity)
#     … ⇛ El (𝕤 ī)        a POINT constructor into sort 𝕤
#     … ⇛ El (l ≡ r)      an EQUATION constructor (imposes l ≐ r)
#
# REFLECTION ⌊·⌋ interprets checked ToS syntax as Nova syntax (the two
# zones linearized in binder order). It is given as TYPED RULES after
# the well-formedness judgements below, whose derivations it computes
# on. Reflection is used ONLY by the OUTER formers (ty-qiit,
# el-qiit-*), to give a QIIT sort/constructor its Nova type; the ToS
# system itself never reflects.
#
# META-OPERATIONS (each ≜-defined by meta-level induction, like the
# substitution actions; A ranges over Nova types, Ξ over Nova
# telescopes, Φ over qiit-contexts).
#
# Nova plumbing — context extension by a telescope, telescope
# weakening:
#     Γ·ε ≜ Γ                     ↑ε ≜ id
#     Γ·(A ◁ Ξ) ≜ (Γ ▷ A)·Ξ       ↑(A ◁ Ξ) ≜ ↑ ∘ ↑Ξ    # the ↑Ξ at Γ ▷ A
#     (↑Ξ : Γ·Ξ ⇒ Γ, so [↑Ξ] weakens over Ξ)
#
# LOOKUP Φ‖ᵢ — the type of ⬡ᵢ in Φ, weakened to all of Φ (mirrors
# Nova's Γ‖ᵢ, with the ToS shift):
#     (Φ ▷ 𝔄)‖₀   ≜ 𝔄[⇑]
#     (Φ ▷ 𝔄)‖ᵢ₊₁ ≜ (Φ‖ᵢ)[⇑]
#
# OPENING (Γ ; Φ) ⋉ 𝔄 — the dual zone reached by walking an El-ended
# type's binders, each into ITS zone (written Γ_𝔄 ; Φ_𝔄 when the base
# zone is clear):
#     (Γ ; Φ) ⋉ El 𝕦        ≜ Γ ; Φ

# one ADMISSIBLE rule per ToS judgement, computed by the ≜-clauses

# STATE 𝑤 = (Γ̂, ρ, υ) — the ρ and υ a clause uses are the components

#     Γ̂   the MERGED context so far — both zones linearized in binder

# in both zones, so ρ lifts; the inductive step is merged-only, so ρ

# IDENTITY (structural). 𝒮.𝕤 ē carries the signature 𝒮; two QIIT types
# are equal exactly when their signatures, sorts (positions), and

# iso-recursive — it never unfolds the fixpoint into its carrier, and
# needs no equirecursive/coinductive machinery. (Signature equality is
# finer than initial-algebra isomorphism — it distinguishes entry
# reorderings — but SOUND; choosing a syntactic granularity over the
# semantic one is the commitment the code-injectivity block already
# makes: models collapsing structurally-distinct types are excluded.)

# substitutions, unfold only on mismatch — nothing QIIT-specific, and it
# keeps the common case cheap without any bespoke rule. Consequently the
# theory is UNIFORMLY structural, QIITs included, so (/) is a genuine

# The ᴰ-clauses walk like reflection, in the ᴰ-STATE (𝑤 ; π) — the
# reflection walk state paired with the PROJECTION π from the
# ᴰ-context so far onto the plain merge so far (Γ̂ of 𝑤), forgetting
# the IH slots. As with 𝑤, the π a clause uses is bound by its
# subscript. The steps (argument slots are shared, so π lifts; IH
# slots are ᴰ-only, so π weakens):
#     (𝑤 ; π) ▷ᴰ A          ≜ (𝑤 ▷ A ; π⁺)
#     (𝑤 ; π) ▷ᴰ El (𝕤 ī)   ≜ (𝑤 ▷ El (𝕤 ī) ; π⁺ ∘ ↑)
#     (𝑤 ; π) ▷ᴰ El (l ≡ r) ≜ (𝑤 ▷ El (l≡r) ; π⁺)
# Initial state (𝑤₀ ; id); the FINAL π of an entry's walk is the πᴰ
# appearing in the rules (mimg, eprob):

(El (𝕤 ī))ᴰ_{𝑤;π}⟨e⟩        ≜ C_𝕤[⌊ī⌋_𝑤[π], e[π]]     # the base: π is final
(A ⇛ 𝔄)ᴰ_{𝑤;π}⟨e⟩           ≜ A[ρ][π] → 𝔄ᴰ_{(𝑤;π) ▷ᴰ A}⟨e⟩
(El (𝕤 ī) ⇛ 𝔄)ᴰ_{𝑤;π}⟨e⟩    ≜ ⌊El (𝕤 ī)⌋_𝑤[π] → C_𝕤[⌊ī⌋_𝑤[π][↑], ☐₀]
                                 → 𝔄ᴰ_{(𝑤;π) ▷ᴰ El (𝕤 ī)}⟨e⟩
(El (l ≡ r) ⇛ 𝔄)ᴰ_{𝑤;π}⟨e⟩  ≜ ⌊El (l≡r)⌋_𝑤[π]
                                 → 𝔄ᴰ_{(𝑤;π) ▷ᴰ El (l≡r)}⟨e⟩          # no IH

(El 𝕦)ᴰᵗ_{𝑤;π}            ≜ ε
(A ⇛ 𝔄)ᴰᵗ_{𝑤;π}           ≜ A[ρ][π] ◁ 𝔄ᴰᵗ_{(𝑤;π) ▷ᴰ A}
(El (𝕤 ī) ⇛ 𝔄)ᴰᵗ_{𝑤;π}    ≜ ⌊El (𝕤 ī)⌋_𝑤[π] ◁ C_𝕤[⌊ī⌋_𝑤[π][↑], ☐₀]
                               ◁ 𝔄ᴰᵗ_{(𝑤;π) ▷ᴰ El (𝕤 ī)}
(El (l ≡ r) ⇛ 𝔄)ᴰᵗ_{𝑤;π}  ≜ ⌊El (l≡r)⌋_𝑤[π] ◁ 𝔄ᴰᵗ_{(𝑤;π) ▷ᴰ El (l≡r)}
                                                            # no IH slot

# ☐₁ and its induction hypothesis ☐₀. In the rules, unsubscripted

# DISPLAYED ALGEBRA — motives plus a method per point constructor:

Γ ⊦ C̄ : 𝒮 mot
for each point position 𝕔 of 𝒮 (𝒮(𝕔) = 𝔄; δ = ⌊𝔄⌋ᵗ's variables):
    Γ ⊦ m_𝕔 : 𝔄ᴰ⟨𝒮.𝕔 δ⟩
--------------------------------------------------------------- (dalg)
Γ ⊦ (C̄ ; m̄) : 𝒮 dalg
# (𝒮.𝕔 δ — the SATURATED constructor at the merge's own variables —
# is the e whose coverage the method provides.)

# METHOD IMAGE ⟦·⟧ — relative to a displayed algebra: the image of a
# qiit-term under the methods, with induction hypotheses read off the
# displayed telescope. Stated at the full OPENING of the entry type,
# concluded in its ᴰ-context. ⟦·⟧ walks APPLICATION CHAINS only, never
# binders, so all its clauses are at one fixed state — the final
# ᴰ-state (𝑤_𝔄 ; πᴰ) — and the ρ, υ, πᴰ below are its components:

Γ ⊦ (C̄ ; m̄) : 𝒮 dalg      𝒮(𝕜) = 𝔄  (𝔄 El-ended)
(Γ ; 𝒮) ⋉ 𝔄 ⊦ 𝕥 : El (𝕤 ī)
---------------------------------------------------- (mimg)
Γ·𝔄ᴰᵗ ⊦ ⟦𝕥⟧ : C_𝕤[⌊ī⌋[πᴰ], ⌊𝕥⌋[πᴰ]]

⟦⬡ᵢ⟧    ≜ ☐_{d(i)}          # d(i) = ⬡ᵢ's IH slot in 𝔄ᴰᵗ (a meta-level
                             #   index computation, like m(i))
⟦𝕔⟧     ≜ m_𝕔[↑𝔄ᴰᵗ]        # a point-constructor head, weakened in
⟦𝕥 t⟧   ≜ ⟦𝕥⟧ (t[ρ][πᴰ])
⟦𝕥 𝕥'⟧  ≜ ⟦𝕥⟧ (⌊𝕥'⌋[πᴰ]) ⟦𝕥'⟧          # 𝕥' at a sort code: value, image
⟦𝕥 𝕡⟧   ≜ ⟦𝕥⟧ (⌊𝕡⌋[πᴰ])                # 𝕡 at an equation code: value only

# ELIMINATION PROBLEM — a displayed algebra whose COHERENCES hold: per
# equation constructor, the method images of the two sides agree.
# This is quot-elim's f⁼, one per equation, with no transport
# (extensional: C[…,⌊l⌋[πᴰ]] ≐ C[…,⌊r⌋[πᴰ]] since ⌊l⌋ ≐ ⌊r⌋ by
# el-qiit-path). Coherences are CHECKED, not stored — the eliminator
# term carries ℰ = (C̄ ; m̄) only:

Γ ⊦ ℰ : 𝒮 dalg
for each equation position 𝕔 of 𝒮
    (𝒮(𝕔) = 𝔄, ending in El (l ≡ r), the sides at code 𝕤 ī):
    Γ·𝔄ᴰᵗ ⊦ ⟦l⟧ ≐ ⟦r⟧ : C_𝕤[⌊ī⌋[πᴰ], ⌊l⌋[πᴰ]]
------------------------------------------------------------ (eprob)
Γ ⊦ ℰ : 𝒮 eprob

# SECTION CANDIDATE — one term per sort, in the motive's context; and
# the SECTION SPINE θ⟨φ⟩, a Nova spine for the displayed telescope
# that interleaves θ with the φ-images of its inductive components
# (θ's component at each binder written b):

Γ ⊦ C̄ : 𝒮 mot
for each sort position 𝕤 of 𝒮 (𝒮(𝕤) = 𝔎):
    Γ·⌊𝔎⌋ᵗ ▷ 𝒮.𝕤 δ ⊦ φ_𝕤 : C_𝕤
--------------------------------------------- (sect)
Γ ⊦ φ : C̄ sect

Γ ⊦ φ : C̄ sect      𝒮(𝕜) = 𝔄  (𝔄 El-ended)      Γ ⊦ θ : ⌊𝔄⌋ᵗ
----------------------------------------------------------------- (sect-spine)
Γ ⊦ θ⟨φ⟩ : 𝔄ᴰᵗ

(El 𝕦)⟨φ⟩           ≜ ·
(A ⇛ 𝔄)⟨φ⟩          ≜ b, 𝔄⟨φ⟩
(El (𝕤 ī) ⇛ 𝔄)⟨φ⟩   ≜ b, φ_𝕤 ⌊ī⌋ b, 𝔄⟨φ⟩
(El (l ≡ r) ⇛ 𝔄)⟨φ⟩ ≜ b, 𝔄⟨φ⟩                    # no IH slot
# (b is θ's component at the binder — the clauses consume θ in order,
# and each ⌊ī⌋ is at the current walk state INSTANTIATED by the spine
# consumed so far, [id, θ↾] — so every component lives over Γ. Then
# m θ⟨φ⟩ : C_𝕤[⌊ī⌋[θ], e[θ]] for m : 𝔄ᴰ⟨e⟩, by the read-out note.)

Γ ⊦ 𝒮 qsig      𝒮(𝕤) = 𝔎      Γ ⊦ ℰ : 𝒮 eprob
Γ ⊦ ē : ⌊𝔎⌋ᵗ      Γ ⊦ w : 𝒮.𝕤 ē
------------------------------------------------------ (el-qiit-elim)
Γ ⊦ 𝒮.𝕤-elim ℰ ē w : C_𝕤[ē, w]

# COMPUTATION (β) — at the saturated constructor (its sort and indices
# read off 𝕔's type). φᵉˡ is the family φᵉˡ_𝕤 ≜ 𝒮.𝕤-elim ℰ δ ☐₀ —
# a section candidate, by el-qiit-elim.

Γ ⊦ 𝒮 qsig      𝒮(𝕔) = 𝔄  (𝔄 ending in El (𝕤 ī))
Γ ⊦ ℰ : 𝒮 eprob      Γ ⊦ θ : ⌊𝔄⌋ᵗ
------------------------------------------------------ (el-qiit-beta)
Γ ⊦ 𝒮.𝕤-elim ℰ ⌊ī⌋[θ] (𝒮.𝕔 θ) ≜ m_𝕔 θ⟨φᵉˡ⟩ : C_𝕤[⌊ī⌋[θ], 𝒮.𝕔 θ]
#   the RHS is 𝕔's method image with the hypotheses supplied by elim
#   itself. EQUATION constructors have NO β-rule (their content is a
#   judgement).

# UNIQUENESS (η) — the section is unique (initiality): any candidate
# that commutes with every point constructor IS the eliminator.

Γ ⊦ ℰ : 𝒮 eprob      Γ ⊦ h : C̄ sect
for each point position 𝕔 of 𝒮 (𝒮(𝕔) = 𝔄, ending in El (𝕤 ī);
                                θ = ⌊𝔄⌋ᵗ's variables):
    Γ·⌊𝔄⌋ᵗ ⊦ h_𝕤[⌊ī⌋, 𝒮.𝕔 θ] ≐ m_𝕔 θ⟨h⟩ : C_𝕤[⌊ī⌋, 𝒮.𝕔 θ]
𝒮(𝕤) = 𝔎      Γ ⊦ ē : ⌊𝔎⌋ᵗ      Γ ⊦ w : 𝒮.𝕤 ē
------------------------------------------------------------- (el-qiit-eta)
Γ ⊦ h_𝕤[ē, w] ≐ 𝒮.𝕤-elim ℰ ē w : C_𝕤[ē, w]
#   any h satisfying the β-equations equals elim: two maps out of a
#   QIIT that agree on all constructors are equal (el-nat-eta /
#   el-quot-eta, generalized).

# SUBSTITUTION ACTION. Substitution acts through the carried signature:
#     (𝒮.𝕤 ē)[σ]          ≜ 𝒮[σ].𝕤 ē[σ]     (type and code)
#     (𝒮.𝕔 θ)[σ]          ≜ 𝒮[σ].𝕔 θ[σ]
#     (𝒮.𝕤-elim ℰ ē w)[σ] ≜ 𝒮[σ].𝕤-elim ℰ[σ] ē[σ] w[σ]
# where 𝒮[σ] and ℰ[σ] are the ToS substitution meta-operation (defined
# with the grammar above): σ on every embedded Nova piece, lifted over
# the external binders in scope; inductive variables untouched.

# CONGRUENCE and INJECTIVITY are STRUCTURAL: equal QIIT types/codes have
# equal signatures, sort positions, and index spines, and conversely —
# the signature compared componentwise (entry by entry; qiit-types and
# qiit-terms as plain indexed syntax — nameless, no α — their embedded
# Nova pieces by the existing congruence/injectivity rules). Stated by
# that meta-recursion rather than spelled per entry, and sound by the
# same canonical-forms commitment as the other formers' inj rules.

# NOTES.
#   * SUBSUMPTION. ℕ is 𝒮.𝕟 · for 𝒮 = (𝕟 : U; Z : El 𝕟;
#     S : (𝕧 : El 𝕟) ⇛ El 𝕟). The quotient A / R is 𝒮.𝕢 · for the
#     signature under IDENTITY above. The disjoint union A ⊎ B is
#     𝒮.𝕤 · for 𝒮 = (𝕤 : U; inl : (x : A) ⇛ El 𝕤;
#     inr : (y : B) ⇛ El 𝕤) — two external-domain points, no
#     equations; its eliminator's β and η are el-qiit-beta/-eta at
#     that signature, which is exactly why ⊎'s standalone rules could
#     be READ OFF the scheme. An indexed inductive type
#     (well-founded trees included) is a sorts-and-points signature:
#     sorts with index arities over I, one point constructor per node
#     shape whose inductive binders are the subtrees. Because QIIT
#     equality is structural (IDENTITY above), these are genuine
#     equalities, not just encodings: ℕ and (/) are kept for
#     convenience but are now DERIVABLE, each a one-line signature.
#     (The levels agree — ℕ's signature embeds no Nova types at all,
#     so it is bounded by 0, and a quotient's, A : 𝕌ℓ with R : Ω, is
#     bounded by A's level — so ty-nat/ty-quot at every level are
#     subsumed too.)
#   * RELAXATION. Strict positivity is GRAMMATICAL — Π domains are
#     only Nova types (sort-free: the Nova zone has no inductive
#     variables) or El-codes; U and Π-types never occur left of a ⇛.
#     This grammar is the DECIDABLE proxy for a semantic condition:
#     that the signature's operator be monotone on the lattice of
#     relations (the setoid congruences over the carrier). A
#     future revision could widen the domain grammar and instead
#     discharge a monotonicity obligation as an ordinary premise,
#     admitting monotone-but-not-positive operators; postulated here
#     in the positive fragment only.
#   * SEMANTICS. The postulate asserts that 𝒮's INITIAL ALGEBRA exists
#     in the setoid model: carriers are the constructor terms, the
#     setoid relation is the congruence GENERATED by the equation
#     constructors (no quotienting step — coarsening the relation IS
#     the quotient), 𝒮.𝕤-elim is the unique section into any displayed
#     algebra (el-qiit-eta), and β holds on the nose. This is the
#     initiality commitment of Altenkirch–Kaposi–Kovács (finitary QIITs),
#     transported to the proof-irrelevant setoid setting where the
#     coherence tower degenerates. As with the injectivity rules,
#     models that fail initiality are hereby excluded.

# EXAMPLE (inductive-inductive: contexts and types). The signature
#     𝒮 = ( Con : U
#         ; Ty  : (𝕘 : El Con) ⇛ U
#         ; ⋄   : El Con
#         ; ext : (𝕘 : El Con) ⇛ (𝕒 : El (Ty 𝕘)) ⇛ El Con      # Γ ▷ A
#         ; u   : (𝕘 : El Con) ⇛ El (Ty 𝕘)
#         ; pi  : (𝕘 : El Con) ⇛ (𝕒 : El (Ty 𝕘))
#                   ⇛ (𝕓 : El (Ty (ext 𝕘 𝕒))) ⇛ El (Ty 𝕘) )
#   gives types 𝒮.Con · and 𝒮.Ty c (Ty indexed by Con); induction is
#   induction-induction — a motive for Con and one for Ty over it, the
#   methods respecting the dependency.
#
# EXAMPLE (quotient: finite multisets over an external type A).
#     𝒮 = ( Bag : U
#         ; nil : El Bag
#         ; ins : (x : A) ⇛ (𝕞 : El Bag) ⇛ El Bag              # x ∷ m
#         ; swp : (x y : A) ⇛ (𝕞 : El Bag)
#                   ⇛ El (ins x (ins y 𝕞) ≡ ins y (ins x 𝕞)) )
#   swp is an equation constructor; 𝒮.Bag ·'s eliminator carries the
#   coherence premise that the method for ins is invariant under
#   swapping the two heads — the multiset laws, no transport.

# Signature references. These three rules serve EVERY entry, type
# entries included: at an A = 𝕌ℓ entry the conclusion index A[e˲]
# computes to 𝕌ℓ by ty-sub-atoms — the former ty-sig-var,
# ty-sig-beta, ty-sig-decl are the A = 𝕌ℓ instances.

(Γ ⊦ x ≔ a : A) ∈ Σ
e˲ : Δ ⇒ Γ norm
------------------------ (el-sig-var)
Σ Δ ⊦ x[e˲] : A[e˲]

(Γ ⊦ x ≔ a : A) ∈ Σ
e˲ : Δ ⇒ Γ norm
------------------------------ (el-sig-beta)
Σ Δ ⊦ x[e˲] ≜ a[e˲] : A[e˲]

# Open-signature references (see DEFINITIONAL AND OPEN SIGNATURES): a
# declaration types its references but never unfolds them (no -beta).
# An assumed equation needs no rule of its own: it is a hole h at the
# equation's prop, and el-sig-decl + el-reflect give
# a₀[e˲] ≐ a₁[e˲] : A[e˲] from the reference h[e˲] — the retired
# el-sig-eq, derived.

(Γ ⊦ x : A) ∈ Σ
e˲ : Δ ⇒ Γ norm
--------------------- (el-sig-decl)
Σ Δ ⊦ x[e˲] : A[e˲]

# Substitution action: t[σ] is defined by ONE meta-level induction
# on the term sort — the ≜-equations below together with the
# type-former clauses in the type rules (ty-sub-*). el-sub, el-sub-id
# and el-sub-comp below state the general facts for the WHOLE sort:

--------------------------------- (el-sub-star)

///////// Coinductive types (polynomial codes) /////////
#
# The dual scheme to QIITs, in its smallest useful form: for each
# POLYNOMIAL 𝔽 — a one-hole strictly positive code, no binders over
# the hole, no internal fixpoints — the rules below license the
# coinductive type ν 𝔽, its observation out (the ELIMINATOR), its
# corecursor corec (the INTRODUCTION), a β-law running one
# observation step, and a uniqueness law (η) that IS the coinduction
# principle. The polarity is Π's, not ℕ's: canonical forms are
# corec-headed, out forces lazily, and elements are compared by
# observation. Like a QIIT signature, 𝔽 is not a Σ-entry and mints
# no names — it is carried by the formers and compared structurally.
#
# THE EXTENSIONAL PAYOFF, dual to the QIIT section's: uniqueness of
# the corecursor is a plain judgemental rule. In intensional
# theories judgemental finality is rejected as undecidable, and
# coinductive equality degenerates into hand-rolled bisimulation
# setoids; here ≐ is already reflection-strong, so el-nu-eta is
# homogeneous with el-qiit-eta — and BISIMULATION IMPLIES EQUALITY
# becomes a corollary rather than a discipline.

# POLYNOMIALS — grammar. External pieces are types at a level, and a
# polynomial is BOUNDED by ℓ, written 𝔽 ≼ ℓ, when each of them is
# typed at 𝕌ℓ (one bound for the whole polynomial, as for a
# signature); ν 𝔽 is a type at that level. A left-hand type `a` BINDS a
# Nova variable in its body, exactly as code-sigma/code-pi bind; the
# two product forms are distinguished by their left-hand side (K a
# × … is the non-binding instance of the same shape). The hole 𝕏
# never occurs left of a → — strict positivity is GRAMMATICAL, with
# nothing to check (the same decidable-proxy commitment as
# RELAXATION in the QIIT notes: here the semantic condition is that
# 𝔽's operator be monotone on the setoid lattice).

#   polynomial
    𝔽, 𝔾 ::= 𝕏               # the hole
           | K a             # constant at a code
           | 𝔽 × 𝔾           # product
           | 𝔽 ⊎ 𝔾           # sum — onto the native ⊎
           | a × 𝔽        # dependent pair over external data
                             #   (binds a NOVA variable)
           | a → 𝔽        # exponent with external domain
                             #   (binds a NOVA variable)

    ⌊a → 𝔽⌋(c)   ≜ a → ⌊𝔽⌋(c[↑])

# FUNCTORIAL ACTION map_𝔽 — for Γ ⊦ g : c₀ → c₁, a function
# term Γ ⊦ map_𝔽 g : ⌊𝔽⌋(c₀) → ⌊𝔽⌋(c₁), ≜-defined by
# meta-level induction on 𝔽 (clauses written applied; at the binding
# formers the recursion proceeds at the instantiated body and g
# weakens under the binder; the sum clause is ⊎-elim at constant
# motive):

    map_𝕏 g x             ≜ g x
    map_{K a} g x         ≜ x
    map_{𝔽 × 𝔾} g p       ≜ (map_𝔽 g (p .π₁) , map_𝔾 g (p .π₂))
    map_{𝔽 ⊎ 𝔾} g s       ≜ ⊎-elim (inj₁ (map_𝔽 g[↑] ☐₀)) (inj₂ (map_𝔾 g[↑] ☐₀)) s
    map_{a × 𝔽} g p    ≜ (p .π₁ , map_𝔽 g (p .π₂))
    map_{a → 𝔽} g f    ≜ λ (map_𝔽 g[↑] (f[↑] ☐₀))

# The FUNCTOR LAWS — map_𝔽 (λ ☐₀) ≐ λ ☐₀ and
# map_𝔽 (g₁ ∘ g₀-composite) ≐ map_𝔽 g₁ ∘ map_𝔽 g₀ pointwise — are
