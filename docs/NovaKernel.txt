Γ ⊦ [α] t₀ ≐ t₁ ⇒ T    // Given core context Γ and a surface proof infer the core equation LHS, RHS and type
Γ ⊦ [α] t₀ ≐ t₁ ⇐ T    // Given core context Γ, core type T and a surface proof infer the core equation LHS, RHS
[ᾱ] ē₀ ≐ ē₁ ⇐ (Γ ⇒ Δ norm)    // spine equation, entrywise, at the type instantiated by ē₁'s prefix
Γ ⊦ [φ] 𝔽₀ ≐ 𝔽₁ poly ℓ        // polynomial equation proof at level ℓ, synthesising both sides

// NOTATION. Γ ⊦ t ⇐ T and Γ ⊦ t ⇒ T abbreviate Γ ⊦ [t] t ≐ t ⇐ T and
// Γ ⊦ [t] t ≐ t ⇒ T: a term with no proof leaf is its own reflexivity
// proof. A TYPE is a term at a SORT
//   U ::= Ω | 𝕌ℓ         (ℓ a natural-number literal; |Ω| = 0, |𝕌ℓ| = ℓ),
// so "T is a type" is Γ ⊦ T ⇒ U, and an equation of types is an equation
// at a sort. There is no judgement of types, and no judgement of type
// equations, beside the two above. (The ToS universe symbol U in the
// QIIT section is unrelated.)

// CONVENTIONS.
// * A non-linear metavariable occurrence, or a former pattern (A → B, A × B,
//   t₀ ≡ t₁ ∈ T, …) in an input position, means equality modulo substitution
//   and β — weak-head β for a pattern, full β for a comparison. "β" is every
//   computation rule: β, the ι-rules, let-β, ν-β, QIIT-β. NEVER δ:
//   definitions unfold only through the proof former x-δ. Every comparison
//   runs under a FUEL budget (equality reflection makes β-normalisation of a
//   well-typed term diverge under an inconsistent hypothesis); exhaustion is
//   rejection, so the checker is total.
// * NO δ FOR EXPOSURE EITHER. A pattern input (λ against a Π, a quot-elim
//   scrutinee against a quotient, ⋆ against a prop) is matched after
//   weak-head β only; a reference at the head is STUCK, and the term is
//   rejected unless an ascription (t : T by α) exposes the shape, α a chain
//   of x-δ leaves naming each unfolding at its path. The reason: whnf-δ in
//   the checker would fix ONE unfolding strategy in the trusted base — the
//   producer would have to predict it step for step, its spellings would
//   leak into every downstream type and report, and its one wasteful case
//   (unfolding a scrutinee that then fails to make ι fire, leaving a larger
//   stuck term) could never be improved without changing what the checker
//   accepts. With δ explicit, over-normalisation is a PRODUCER quality —
//   visible as proof size, fixable by a better strategy or a lemma, never a
//   checker semantics. The producer should unfold PROGRESS-ONLY: the head
//   while it yields a former, a scrutinee only if ι then fires, rolled back
//   otherwise; the emitted chain is the shortest δ-sequence to the shape.
//   Without δ, β-normal forms are bounded by the written term's own redexes:
//   every blow-up the corpus shows is δ, and it now happens on the untrusted
//   side and is recorded.
// * SORTS ARE CUMULATIVE, Ω ≤ 𝕌₀ ≤ 𝕌₁ ≤ …: a proposition is a small type, a
//   small type is a large one. Cumulativity enters through exactly two proof
//   forms, lift and restrict (the modal section) — never silently — and acts
//   at the ROOT only: A → Ω is not A → 𝕌₀ (write λx. f x). Levels are
//   literals: no level polymorphism; a statement over (A : 𝕌₀) lives at 𝕌₁.
//   A former INFERS its least sort (the arithmetic on ℓ ⊔ ℓ′ below) and is
//   used at any higher one through lift; the checker never guesses a
//   universe.
// * Ω HAS NO CODE BELOW 𝕌₁: Ω ⇒ 𝕌₁ and never Ω ⇒ 𝕌₀, so A → Ω is a 𝕌₁ type
//   for every A (Cantor stays a theorem; the effective topos refutes Ω : 𝕌₀,
//   a program cannot tell two propositions apart, while validating every
//   p : Ω at 𝕌₀). Individual propositions ARE 𝕌₀ codes, by Ω ≤ 𝕌₀. Every
//   𝕌ℓ's equality is thereby MIXED: structural on the formers, extensional
//   (propext) on the proposition cluster; an equation across the clusters is
//   underivable by absence, and the injectivity selectors act on same-headed
//   formers only.
// * ELIMINATORS NAME THEIR SORT: the U on ℕ-elim, ⊎-elim, quot-elim and the
//   QIIT eliminator is the sort the motive lands in, an INPUT the motive is
//   checked at, never computed from it. U = Ω is where well-definedness and
//   coherences close by irrelevance.

// ===== COVERAGE: QIITs =====
// A signature 𝒮 is CARRIED by the core (𝒮.𝕤 ē, 𝒮.𝕔 θ, 𝒮.𝕤-elim m̄ ē w):
// QIIT equality is structural on it and β reads it (el-qiit-beta
// recurses by the constructor's arity). It is WRITTEN in the theory of
// signatures below — the grammar is the positivity guarantee, and β
// reads constructor arities off it — and it is TYPED through its
// reading as a Nova telescope, ⟦𝒮⟧, over the ALGEBRA CONTEXT Γ · ⟦𝒮⟧:
// an algebra is a spine of that telescope; the initial algebra ι is the
// spine of the formers themselves; the eliminator's motives, methods
// and coherences are ONE spine of the displayed telescope ⟦𝒮⟧ᴰ over ι;
// the eliminator's type and its β are substitutions. Nothing about the
// ToS is trusted beyond the readings ⟦_⟧ and _ᴰ and the displayed spine
// θᴰ, each defined by recursion on the grammar and landing in Nova
// syntax the rules above already read. The eliminator's core carries
// the METHODS only: motives, coherences and the sorts Ū the motives
// land in are SURFACE, as ℕ-elim's A and U are.
// A signature is checked AT A LEVEL ℓ, its BOUND: every Nova type it
// embeds at 𝕌ℓ (a proposition included, by Ω ≤ 𝕌₀ ≤ 𝕌ℓ), its sorts
// types at 𝕌ℓ, ⟦𝒮⟧ a telescope with sort entries at 𝕌ℓ₊₁. One bound
// serves every sort. The former SMALLNESS condition ("every external
// domain at 𝕌 or at Ω, tried in turn") is gone: one check at 𝕌ℓ, no
// universe guessed.

// --- Telescopes and spines (the Nova notation the readings land in) ---

Δ ::= · | Δ ▷ A          // a telescope over Γ: snoc, each entry a type over Γ and the entries before it
Γ · Δ                    // the context Γ extended by Δ, entry by entry
↑Δ                       // weakening past Δ: ↑ iterated |Δ| times
ē : (Γ ⇒ Δ)              // a SPINE: entrywise eᵢ ⇐ Δ∥ᵢ[id, e₀ … eᵢ₋₁]; as a substitution (id, ē) : Γ ⇒ Γ · Δ
X[ē]                     // X over Γ · Δ instantiated by the spine: X[(id, ē)]; likewise Δ′[ē] for a telescope over Γ · Δ
Δ∥ᵢ                      // the i-th entry, over Γ · (the entries before it)

// --- The theory of signatures (surface = core: nameless indexed syntax) ---

Φ, 𝒮 ::= ⬦ | Φ ▷ 𝔄                       // a signature is a closed qiit-context
𝔄 ::= U | El 𝕥 | A ⇛ 𝔄 | El 𝕥 ⇛ 𝔄        // A a Nova type; ⇛ binds a Nova / a ToS variable
𝕥 ::= ⬡ᵢ | 𝕥 t | 𝕥 𝕥 | λ 𝕥 | 𝕥 ≡ 𝕥        // t a Nova term; the equation code at the sides' common sort

Γ ⊦ Φ qctx ℓ           // Given core Γ, check surface Φ at level ℓ (elaborating its Nova pieces)
Γ ; Φ ⊦ 𝔄 qty ℓ
Γ ; Φ ⊦ 𝕥 ⇒ 𝔄          // ToS terms INFER: they are variables and application chains
Γ ; Φ ⊦ 𝕥 ⇐ 𝔄
Γ ⊦ 𝒮 qsig ℓ  ≜  Γ ⊦ 𝒮 qctx ℓ
Γ ⊦ [ϑ] 𝒮₀ ≐ 𝒮₁ qsig ℓ  // signature equation: 𝒮 with each embedded Nova piece replaced by a proof
                        //   (a type piece by an equation at 𝕌ℓ, a term piece by a proof at its type);
                        //   the ToS structure itself is compared syntactically — no α, no β
                        //   (likewise [ψ] 𝔄₀ ≐ 𝔄₁ qty ℓ, [θ] 𝕥₀ ≐ 𝕥₁ qtm)

                     ----------------------------------              -----------------
                     Γ ⊦ Φ ▷ 𝔄 qctx ℓ                                Γ ; Φ ⊦ U qty ℓ

Γ ; Φ ⊦ 𝕥 ⇐ U         Γ ⊦ A ⇐ 𝕌ℓ      Γ ▷ A ; Φ[↑] ⊦ 𝔄 qty ℓ      Γ ; Φ ⊦ 𝕥 ⇐ U      Γ ; Φ ▷ El 𝕥 ⊦ 𝔄 qty ℓ
----------------      -------------------------------------     ----------------------------------------
Γ ; Φ ⊦ El 𝕥 qty ℓ    Γ ; Φ ⊦ A ⇛ 𝔄 qty ℓ                        Γ ; Φ ⊦ El 𝕥 ⇛ 𝔄 qty ℓ

Γ ; Φ ⊦ ⬡ᵢ ⇒ Φ‖ᵢ

Γ ; Φ ⊦ 𝕥 ⇒ A ⇛ 𝔄      Γ ⊦ t ⇐ A          Γ ; Φ ⊦ 𝕥 ⇒ El 𝕦 ⇛ 𝔄      Γ ; Φ ⊦ 𝕥' ⇐ El 𝕦
----------------------------------        -------------------------------------------
Γ ; Φ ⊦ 𝕥 t ⇒ 𝔄[id, t]                    Γ ; Φ ⊦ 𝕥 𝕥' ⇒ 𝔄[𝕥']

------------------------      ------------------------------------------      ------------------------- // mode switch
Γ ; Φ ⊦ λ 𝕥 ⇐ A ⇛ 𝔄           Γ ; Φ ⊦ 𝕥₀ ≡ 𝕥₁ ⇐ U                              Γ ; Φ ⊦ 𝕥 ⇐ 𝔄
                                                                              // (β on the embedded Nova pieces only)

// --- The reading ⟦_⟧: a signature as a telescope, its terms as Nova terms ---
// ⟦Φ⟧ is a telescope over Γ. For Γ ; Φ ⊦ 𝔄 qty ℓ and Γ ; Φ ⊦ 𝕥 ⇒ 𝔄,
// ⟦𝔄⟧ is a type and ⟦𝕥⟧ a term over the algebra context Γ · ⟦Φ⟧, the
// ToS variable ⬡ᵢ being the Nova variable ☐ᵢ of that context. Two
// pieces of bookkeeping: an external Nova piece (a domain A, an
// argument t) is over Γ and is weakened past the algebra, [↑⟦Φ⟧]; the
// ToS λ and the external ⇛ bind a NOVA variable while the ToS context
// is weakened, so their bodies are read over Γ ▷ A · ⟦Φ[↑]⟧ and moved
// to Γ · ⟦Φ⟧ ▷ A[↑⟦Φ⟧] by the EXCHANGE ξ, the substitution that swaps
// the one variable past the telescope (a raw identity on syntax; a
// lemma, not a rule).

⟦⬦⟧          = ·
⟦Φ ▷ 𝔄⟧      = ⟦Φ⟧ ▷ ⟦𝔄⟧

⟦U⟧          = 𝕌ℓ                                   // a sort entry: a type variable at the bound
⟦El 𝕥⟧       = ⟦𝕥⟧                                  // a code at 𝕌ℓ, hence a type
⟦A ⇛ 𝔄⟧      = A[↑⟦Φ⟧] → ⟦𝔄⟧[ξ]                     // external Π
⟦El 𝕥 ⇛ 𝔄⟧   = ⟦𝕥⟧ → ⟦𝔄⟧                            // internal Π: the ToS variable IS the Nova variable

⟦⬡ᵢ⟧         = ☐ᵢ
⟦𝕥 t⟧        = ⟦𝕥⟧ t[↑⟦Φ⟧]
⟦𝕥 𝕥′⟧       = ⟦𝕥⟧ ⟦𝕥′⟧
⟦λ 𝕥⟧        = λ ⟦𝕥⟧[ξ]
⟦𝕥 ≡ 𝕥′⟧     = (⟦𝕥⟧ ≡ ⟦𝕥′⟧ ∈ ⟦𝕦⟧)                    // 𝕦 the sides' common code; a proposition, so a 𝕌₀
                                                    //   code, so an entry like any other (Ω ≤ 𝕌₀)

// An ARITY: a ToS type is D₁ ⇛ … ⇛ Dₙ ⇛ E with E = U or E = El 𝕥.
// Its arity telescope and end are read over Γ · ⟦Φ⟧:
⟦D₁ ⇛ … ⇛ Dₙ ⇛ E⟧ᵗ  = · ▷ ⟦D₁⟧ ▷ … ▷ ⟦Dₙ⟧          // each ⟦Dᵢ⟧ read over the entries before it, ξ applied at the external ones
⟦D₁ ⇛ … ⇛ Dₙ ⇛ E⟧ᵉ  = ⟦E⟧                            // over Γ · ⟦Φ⟧ · ⟦𝔄⟧ᵗ
// so that ⟦𝔄⟧ = Π ⟦𝔄⟧ᵗ. ⟦𝔄⟧ᵉ, the iterated Π over the arity.

// An ALGEBRA of 𝒮 over Γ is a spine ā : (Γ ⇒ ⟦𝒮⟧). The INITIAL algebra
// ι : (Γ ⇒ ⟦𝒮⟧) is the spine of the carried formers, entry by entry:
ι(𝕤)  = λ ⟦𝔎⟧ᵗ. 𝒮.𝕤 (the bound variables)             // for a sort entry 𝒮(𝕤) = 𝔎
ι(𝕔)  = λ ⟦𝔄⟧ᵗ. 𝒮.𝕔 (the bound variables)             // for a point entry 𝒮(𝕔) = 𝔄
ι(𝕔)  = λ ⟦𝔄⟧ᵗ. ⋆                                    // for an equation entry: its end is a proposition
// Every type below is stated in the algebra context and instantiated
// at ι by substitution; X[ι] is X[(id, ι)], and X[ι, θ] extends it by
// a further spine.

// --- The displayed reading _ᴰ: motives, methods, coherences as one telescope ---
// Over the algebra context, for target sorts Ū (one per sort of 𝒮 —
// the sort the sort's motive lands in; the foundation's target levels
// ℓ̄′, with Ω reached by cumulativity), a
// ToS type 𝔄 with algebra value x : ⟦𝔄⟧ has the displayed type 𝔄ᴰ x, and
// a ToS term 𝕥 : 𝔄 has the displayed term 𝕥ᴰ : 𝔄ᴰ ⟦𝕥⟧ — Nova types and
// terms over Γ · ⟦𝒮⟧ · ⟦𝒮⟧ᴰ, the displayed variable ☐ᵢᴰ of ⬡ᵢ bound in
// the displayed telescope:

⟦⬦⟧ᴰ         = ·
⟦Φ ▷ 𝔄⟧ᴰ     = ⟦Φ⟧ᴰ ▷ 𝔄ᴰ ☐_𝔄                          // ☐_𝔄: the algebra's variable for this entry, weakened past the displayed entries before

Uᴰ X                = X → U_𝕤                           // a MOTIVE over the sort's carrier, at the sort's named target U_𝕤;
                                                        //   for an indexed sort (𝔎 = D̄ ⇛ U) the motive is under the arity: Π ⟦𝔎⟧ᵗ. X d̄ → U_𝕤
(El 𝕥)ᴰ x           = 𝕥ᴰ x                              // a METHOD: the displayed term of the entry's code, at x
(A ⇛ 𝔄)ᴰ f          = Π (a : A[↑…]). 𝔄ᴰ (f a)            // external argument: passed through
(El (𝕤 ī) ⇛ 𝔄)ᴰ f   = Π (x : ⟦𝕤 ī⟧) (xᴰ : (𝕤 ī)ᴰ x). 𝔄ᴰ (f x)  // internal argument at a SORT: passed with its
                                                             //   image (the induction hypothesis)
(El (l ≡ r) ⇛ 𝔄)ᴰ f = Π (x : ⟦l ≡ r⟧). 𝔄ᴰ (f x)             // internal argument at an EQUATION code: a proof,
                                                             //   content-free — no displayed slot (its image
                                                             //   would be a proposition that always holds, by
                                                             //   reflection of x and congruence)

⬡ᵢᴰ                 = ☐ᵢᴰ
(𝕥 t)ᴰ              = 𝕥ᴰ t[↑…]
(𝕥 𝕥′)ᴰ             = 𝕥ᴰ ⟦𝕥′⟧ 𝕥′ᴰ                        // 𝕥′ at a sort code: value and image
(𝕥 𝕡)ᴰ              = 𝕥ᴰ ⟦𝕡⟧                             // 𝕡 at an equation code: value only
(λ 𝕥)ᴰ              = λ a. 𝕥ᴰ[ξ]
(𝕥 ≡ 𝕥′)ᴰ p         = (𝕥ᴰ ≡ 𝕥′ᴰ ∈ 𝕦ᴰ ⟦𝕥′⟧)             // a COHERENCE: by reflection of p, ⟦𝕥⟧ ≐ ⟦𝕥′⟧, so both
                                                        //   displayed sides sit at one type; a proposition
// So ⟦𝒮⟧ᴰ[ι] is the telescope of the eliminator's SURFACE arguments in
// signature order — motives at the sort entries, methods at the point
// entries, coherences at the equation entries — and d̄ : (Γ ⇒ ⟦𝒮⟧ᴰ[ι])
// is all of them at once. d̄(𝕤) names the motive entry for sort 𝕤, d̄(𝕔)
// the method entry for point 𝕔, m̄ the point entries (what the core
// keeps). The current document's 𝔄ᴰ⟨e⟩, 𝔄ᴰᵗ, ⟦𝕥⟧ and θ⟨φ⟩ are these
// definitions; ⌊𝔎⌋ᵗ is ⟦𝔎⟧ᵗ[ι].

// --- The outer formers ---

Γ ⊦ 𝒮 qsig ℓ      𝒮(𝕤) = 𝔎      ē ⇐ (Γ ⇒ ⟦𝔎⟧ᵗ[ι])

--------------------------------------------------- //   is a proposition (irrel at U_𝕤 = Ω, a proof otherwise)
Γ ⊦ 𝒮.𝕤-elim Ū d̄ ē w ⇒ d̄(𝕤) ē w                      // core: 𝒮.𝕤-elim m̄ ē w, m̄ the point entries of d̄
