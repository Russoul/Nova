// ===== COVERAGE: QIITs =====
// A signature 𝒮 is CARRIED by the core (𝒮.𝕤 ē, 𝒮.𝕔 θ, 𝒮.𝕤-elim m̄ ē w):
// QIIT equality is structural on it and β reads it (el-qiit-beta
// recurses by the constructor's arity). The eliminator's core carries
// the METHODS m̄ — β reads them — and NOT the motives C̄ or the
// coherences ω̄, which typing alone reads: those are SURFACE, as ℕ-elim's
// A is. So the surface eliminator is 𝒮.𝕤-elim (C̄ ; m̄ ; ω̄) ē w and the
// core one 𝒮.𝕤-elim m̄ ē w. β needs no motive: φᵉˡ_𝕤 ≜ 𝒮.𝕤-elim m̄ δ ☐₀.
// The meta-operations — REFLECTION ⌊𝔄⌋ (a type) and ⌊𝔎⌋ᵗ (an arity
// telescope) and ⌊𝕥⌋ (a term), the DISPLAYED type 𝔄ᴰ⟨e⟩ and telescope
// 𝔄ᴰᵗ relative to motives, the METHOD IMAGE ⟦𝕥⟧, and the SECTION SPINE
// θ⟨φ⟩ — are the foundation's ≜-definitions, computed by the checker;
// ToS substitution likewise. "modulo β" includes el-qiit-beta.
