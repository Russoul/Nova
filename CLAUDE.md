* Use `pack` to type check / build / run idris2 programs
* There is also a Nix flake mirroring `pack.toml`'s pins: `nix build` (the `nova` executable), `nix flake check` (every CI gate), `nix develop` (a shell where `idris2 --build nova.ipkg` works directly). The gate scripts take `NOVA_BIN` / `NOVA_TESTS_BIN` / `NOVA_LSP_BIN` to reuse already-built executables instead of invoking pack
* Use `./test.sh` to run the test suite (passes the required `PATH_TO_SELF` argument automatically); extra golden framework flags (e.g. `--only ty-pi`) can be appended
* To check a Nova surface file, run `build/exec/nova elab <file>.nova` (after `pack build nova.ipkg`): a file is accepted iff the run ends with zero obligations; discharge an obligation by prepending a lemma — an ordinary `def` whose type is the obligation's statement as an equality type — NAMING it in the surfacing item's `using` clause (the report's `hint:` line usually names it for you), and re-running. Discharge is scoped: an item sees only its named lemmas plus hypotheses
* `build/exec/nova distill <file>.nova <out-dir>` renders the file's module closure back to surface text and verifies the round trip (docs/NovaPerfectSurface.txt); `./check-distill.sh` runs it over the whole corpus AND enforces that `src/nova` stays in canonical distill form (byte-identical to its own distillation — after editing corpus files, re-normalize via distill if the gate complains)
* The theory and its implementation are specified in `docs/`: `NovaFoundation.txt` (the type theory — sole source of truth; official reading intrinsic, semantics the setoid model), `NovaModel.txt` (the standard meta-circular model: the setoid model's code layer), `NovaKernel.txt` (the trusted kernel, rule by rule), `NovaElaboration.txt` (surface syntax + elaborator), `NovaPipeline.txt` (the trust architecture), `NovaPerfectSurface.txt` (the perfect (elaborator, printer) pairing: the distill printer, round-trip contract, sugar tiers). Read the relevant spec before the Idris sources — every function mirrors a documented rule
