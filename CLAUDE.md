* Use `pack` to type check / build / run idris2 programs
* There is also a Nix flake mirroring `pack.toml`'s pins: `nix build` (the `nova` library), `nix flake check` (the spec-rules gate: every rule-shaped citation in `src/idris` must name a rule of `docs/`), `nix develop` (a shell where `idris2 --build nova.ipkg` works directly)
* This branch is a FRESH START (2026-09-29): the previous kernel, elaborator, language server, golden tests and gate scripts are frozen on the `dev-freeze` branch for consultation and for copying reusable code; `nova.ipkg` currently builds only the generic library modules (`Control.Monad.*`, `Data.Util`)
* The corpus in `src/nova/` is kept in full as the ACCEPTANCE TARGET of the new pipeline: a file is accepted iff its elaboration ends with zero obligations (an obligation is discharged by a lemma — an ordinary item `name : <the obligation's statement as an equality type>` with its clause `name = …` — named in the surfacing item's `using` clause; discharge is scoped: an item sees only its named lemmas plus hypotheses), and the round-trip contract of docs/NovaPerfectSurface.txt (the corpus byte-identical to its own distillation) is to be restored
* The surface syntax is INDENTATION-SIGNIFICANT: items are keyword-free column-0 lines — a signature `plus : ℕ → ℕ → ℕ` followed by its definiens as the clause `plus = …` (no `def`, `=` not `≔`); pattern clauses are column-0 lines under their signature too (no `|`), and an indented line that begins a term is one more ARGUMENT of the spine above it, parenthesis-free (`ℕ-elim` ⏎ `  x. motive` ⏎ `  z` ⏎ `  k ih. step` ⏎ `  n`)
* The corpus in `src/nova/` is a TREE, and its directories ARE namespace segments: a module's dotted name is its path from `src/nova` (`src/nova/Real/mul.nova` is the module `Real.mul`; `import Real.mul`, entries `Real.mul.x`). The marker file `src/nova/nova.root` is what imports resolve against — the nearest such marker above the file being elaborated — so a nested module elaborates standalone (and under the LSP) exactly as it does inside `src/nova/all.nova`, which imports every module. Groups: `Core/` (equality, prop, id, uip, …), `Lang/` (one language feature per file), `Qiit/`, `Codata/`, `Algebra/`, and the ℕ → ℤ → ℚ → ℝ tower as a base module beside its own directory (`Natural.nova` + `Natural/`, likewise `Int`, `Rat`, `Real`). NOTE `Nat`, `Set`, `Prop`, `Void` and `Unit` are reserved words and cannot be path segments — that is why the ℕ group is `Natural`
* The theory and its implementation are specified in `docs/`: `NovaFoundation.txt` (the type theory — sole source of truth; official reading intrinsic, semantics the setoid model), `NovaKernel.txt` (the trusted kernel, rule by rule), `NovaPipeline.txt` (the trust architecture), `NovaPerfectSurface.txt` (the perfect (elaborator, printer) pairing: the distill printer, round-trip contract, sugar tiers). Read the relevant spec before the Idris sources — every function mirrors a documented rule
